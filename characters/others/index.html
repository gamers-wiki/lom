そのほかの人々

カテゴリ：キャラクター全13人

ひとつづきの物語には収まらない人たちです。武器防具を打つ職人やゴーレムを作る研究者のように、事件よりも施設や作成で世話になる相手も混じっています。

  • ドミナの町の住人
  • マイホームの住人
  • 宝石泥棒編の人々
  • エスカデ編の人々
  • ドラゴンキラー編の人々
  • マナの賢人とその周辺
  • ギルバートと仲良し3人組
  • 海賊と穴掘り団
  • 魔法都市ジオの人々
  • そのほかの人々

マイホームの武具作成室やゴーレム研究室が使えるようになるのは、作成編の『武器防具作成』と『ゴーレム作成』です。

ワッツ WATTS

種族ドワーフ／男／199歳
主な登場場所ウルカン鉱山
関わるイベント『鍛冶屋ただいま閉店中』、『ワッツのハンマー』、『続々々・ニキータ商い道中』、『武器防具作成』
人物
  • ウルカン鉱山に工房を持つ武器防具職人
  • 口グセは「〜だに」
  • 『聖剣伝説』シリーズの常連。ドワーフで大きなカブトをかぶり、武器・防具を作るという役どころは過去作と同じ
人物図鑑No.25（記載条件）

マスター THE MANAGER

種族魔法生物（パズル人）／男／52歳
主な登場場所月夜の町ロア
関わるイベント『精霊の光』、『シュタインベルガー』
人物
  • 月夜の町ロアの酒場「悪魔のぼったくり亭」の主人
  • 酒場の常連はアナグマたち
  • アナグマ語を話せる
  • バーテンと同じ1枚の古い設計図をもとに、魔法学園で創られた魔法生物
  • 設計図を作ったのは、陸・海・空を駆けまわる可変型アーティファクトクリーチャーを創ろうとした魔導士とされる
  • 設計図がなぜパズル型の人間になったのかは不明
  • 店名の「悪魔のぼったくり」は、酒が熟成する過程で量が自然に減る現象を指す言葉（現実世界で「天使のわけまえ」と呼ばれるものにあたる）
ほかの人物との関係
  • バーテン … 弟子。魔法都市ジオにいる
人物図鑑No.29（記載条件）

バーテン BARTENDER

種族魔法生物（パズル人）／男／29歳
主な登場場所魔法都市ジオ
関わるイベント『シュタインベルガー』
人物
  • 魔法都市ジオのフルーツパーラーでバーテンをしている
  • 外見は月夜の町ロアにいるマスターとほとんど変わらない
  • マスターの弟子で、酒に対する考えかたなどを学んだ
  • 以前は「悪魔のぼったくり亭」で修行していた
  • マスターと同じ1枚の古い設計図をもとに、魔法学園で創られた魔法生物
ほかの人物との関係
  • マスター … 師匠。月夜の町ロアの酒場の主人
人物図鑑No.30（記載条件）

ボンボヤジ PROF.BOMB

種族謎の生き物／男／58歳
主な登場場所ゴミ山
関わるイベント『ボンボヤジの研究室』、『ゴーレム作成』
人物
  • ゴミ山に研究室を持ち、実験を続けている
  • 一時はゴーレム研究をしていた
  • 作ったゴーレムが暴走し、実験費用もかさんだ
  • 現在は研究への意欲を失っている
  • 口グセは「〜ぢゃ」
  • 得意技「ボンボコプター」。頭をまわして一瞬宙に浮く
  • オナラの力で宙に浮くこともできる
  • 『聖剣伝説』シリーズの常連。過去作では主人公の移動範囲を広げる役、本作では発明家という点のみが共通
ほかの人物との関係
  • ゴミ山のゴミを再利用してゴーレムのパブロフを作成した
人物図鑑No.39（記載条件）

鳩血鬼 DRACULARK

種族悪魔／不明／671歳
主な登場場所ミンダス遺跡
関わるイベント『危険なアフタヌーンティー』
人物
  • 読みは「きゅうけつき」
  • 性別は不明、年齢は671歳
  • ミンダス遺跡に数百年前から住み着いている
  • 名前の由来は、ハトの血を好んで吸うこと
  • ミンダス遺跡のハトは取りつくされ、いまはいない
  • 獲物を失い、空腹の状態が続いている
人物図鑑No.42（記載条件）

ベル BELLE

種族夢魔／女／65538歳
主な登場場所魔法都市ジオ　ほか
関わるイベント『フローライト』、『夢の檻の中へ』
人物
  • 夢魔の掟では、現実世界とあまり関わってはいけないことになっている
  • 外見と口調は幼い少女のようだが、実年齢は65538歳
  • 語尾に「ですぅ」を付けて話す
  • 夢魔は悪魔の一種
  • バクの背に乗って夢の世界を歩いている
  • 良い夢に行き当たるとバクがそれを食べる
  • あまりに怖い夢に入ると、驚いたバクごと夢から飛び出してしまうことがある
ほかの人物との関係
  • バク … 夢の世界を歩くときに背に乗っている
人物図鑑No.48（記載条件）

マグノリア MAGNOLIA

種族魔法生物／女／670歳
主な登場場所ゴミ山
関わるイベント『災いを呼ぶ人形』
人物
  • 人形師アニュエラが作った人形
  • 核は大魔女アニスが1000年前に作った火石
  • 瞳の部分に火石が入っている
  • ゴミ山で暮らしている
  • 「マグノリア」はもとは人間の少女の名
  • のちの七賢人セルヴァが、アニュエラのもとから人形を持ち出して少女マグノリアに贈った
  • 瞳の火石には、映ったものを発火させる力がある
  • その力で少女の家が焼け、少女は死亡
  • 焼け残った人形が少女の記憶と自分の記憶を混同し、マグノリアを名乗るようになった
ほかの人物との関係
  • 核の火石を作ったのは大魔女アニス
  • 人形師アニュエラが作った人形
  • のちの七賢人のひとり・セルヴァが少女マグノリアに贈った人形
  • ルーイと同じくゴミ山にいる
人物図鑑No.50（記載条件）

ルーイ LOUIE

種族魔法生物／男／883歳
主な登場場所ゴミ山
関わるイベント『災いを呼ぶ人形』
人物
  • ゴミ山に住み、ゴミを管理している
  • アーティファクトクリーチャー
  • 人形師アニュエラが最初に創造した3体の魔法生物のひとつ
  • ほかの2体は妖精戦争時に破壊された
  • 現存する魔法生物のなかでもっとも古い
  • 魔法生物＝肉体を失った魂を容器に降ろし、生き物と同じ能力を持たせたもの
  • 魂の容器になるものは種類が少なく、魔法生物は外見が似通う
  • アーティファクトクリーチャーは、古い時代に異なる技法で創造された魔法生物の呼び名。中身はほかの魔法生物と同じ
ほかの人物との関係
  • 人形師アニュエラが創造した
  • マグノリアと同じくゴミ山にいる
人物図鑑No.54（記載条件）

モティさん MR.MOTI

種族人間／男／28歳前後
主な登場場所ドミナの町、月夜の町ロア、港町ポルポタ
関わるイベント『波間に眠る追憶』
人物
  • 性別は男、年齢は28歳前後
  • モティ村の出身で、各地の宿屋や店にいる
  • 全員が「モティさん」と呼ばれ、その踊りは「モティ踊り」と呼ばれる
  • 得意とするカレーの種類が一人ずつちがう
  • モティ村の人々は、目を見ただけで相手の得意なカレーの種類が分かる
  • ドミナの町のモティさんは、ホウレンソウとチキンのカレー「サグチキン」が得意
  • 港町ポルポタでは、右のモティさんが野菜のカレー「ベイガンバルタ」、左がエビのカレー「ブラウンチリ」を得意とする
  • 月夜の町ロアのモティさんの得意なカレーは不明
  • 過去の『聖剣伝説』シリーズでは店や宿屋にターバン姿の男が登場していたが、名前と外見の由来が明かされたのは本作が初めて
ほかの人物との関係
  • 港町ポルポタのシーサイドホテルにいる踊り子・ルヴァーンシュは、モティさんの親戚だとのウワサがある
人物図鑑No.58（記載条件）

グラシエール GLACIERA

種族悪魔／女／不明
主な登場場所フィーグ雪原
関わるイベント『こおれる過去』
人物
  • 性別は女、年齢は不明
  • 雪女
  • フィーグ雪原に古くから住んでいる
  • 氷晶花の園を守っている
  • 雪原で遭難した者を氷漬けにして魂を吸う、というウワサがある
  • 氷晶花の園は、彼女の知人の珠魅が自分の核である氷晶石を抜き取って雪原にたたきつけたことが始まりだ、という逸話がある
  • いまも友人が眠るその地を守っているとされる
ほかの人物との関係
  • 氷晶花の園の成り立ちの逸話に、知人の珠魅が登場する
人物図鑑No.60（記載条件）

花人 FLOWERLINGS

種族花人／男女あり
主な登場場所ミンダス遺跡、ジャングル、ゴミ山、港町ポルポタ、骨の城
関わるイベント『危険なアフタヌーンティー』、『続々・ニキータ商い道中』、『課外活動』
人物
  • 読みは「はなびと」
  • 性別は男女あり。年齢は記載なし（―）
  • 草人の頭に花が咲くと花人になる
  • 人間社会で売り子などをすることがある
  • 性別が他種族と同じ意味を持つかは不明
  • 草人から受け継ぐのは、意識を共有する「シンクロ」だけ
  • 花人になると口調が変わり、草人独特の世界観は残らない
  • マナの聖域に由来する役割を持つのは草人だけ
  • すべての草人が花人になるわけではない
ほかの人物との関係
  • 草人が変化した姿
人物図鑑No.70（記載条件）

ぶにゅ BUNYIP

種族次元生物／不明／不明
主な登場場所リュオン街道、メキブの洞窟、マドラ海岸、レイリスの塔
関わるイベント『たゆたう歌声』
人物
  • 主人公が行くべきではない道をふさぐ位置にいる
  • 本体にさわると、次元を越えて別の場所に出ているしっぽの地点へ飛ばされる
  • 見た目はモンスターのようだが人畜無害
  • たいていはその場でじっとしているが、たまに4対の足で移動したり、あくびをしたりする
  • 他者がぶにゅを動かすことは難しい
  • リュミヌーに対してはあっさり道を開けた
人物図鑑No.79（記載条件）

パブロフ PAVLOV

種族魔法生物／不明／不明
主な登場場所ゴミ山
関わるイベント『ボンボヤジの研究室』
人物
  • ボンボヤジがゴミ山のゴミから作ったゴーレム
  • 創り主のもとを飛び出し、行方が知れない
  • 世界征服のためのゴーレム軍団を作ろうと、独自に研究している
ほかの人物との関係
  • ボンボヤジが作成したゴーレム
