キャラクター

カテゴリ：キャラクター登場人物92人

ファ・ディールで出会う人たちをまとめたカテゴリです。旅の主役である主人公、 連れて歩ける仲間（NPC）12人、各地で出会う登場人物92人について、 種族や年齢、主な登場場所、関わるイベント、ほかの人物との関係を人物ごとにまとめています。 仲間になる12人も、この92人に含まれます。

登場人物は全10群に分けてあります。物語のまとまりや住む町、人物どうしのつながりでまとめてあるので、 イベントの途中で名前だけ出てきた相手も、そのイベントの群から探せます。 このうち79人はゲーム内の人物図鑑に載ります。

主人公と仲間

  • 主人公 … はじめの能力値と、選んだ武器系統11種で変わる初期装備・必殺技
  • 仲間になる12人（NPC） … 加えかたとはずしかた、人物ごとの加入条件、仲間にいると変わるイベント
  • 仲間になる12人のデータ … 能力値・アビリティ・必殺技と、冒険の進みぐあいで変わる装備

仲間は装備も必殺技も固定で、こちらからは変えられません。誰を連れて行くかを決めるときは、仲間になる12人のデータで武器の系統と必殺技を見比べてください。

登場人物

群ごとのページに、種族・性別・年齢、主な登場場所、関わるイベント、ほかの人物との関係、人物図鑑の番号を並べています。

  • ドミナの町の住人 … 12人
  • マイホームの住人 … 5人
  • 宝石泥棒編の人々 … 16人
  • エスカデ編の人々 … 7人
  • ドラゴンキラー編の人々 … 8人
  • マナの賢人とその周辺 … 9人
  • ギルバートと仲良し3人組 … 4人
  • 海賊と穴掘り団 … 8人
  • 魔法都市ジオの人々 … 10人
  • そのほかの人々 … 13人

群ごとのページでは、仲間にできる人物に加入条件への案内が、人物図鑑に載る人物に番号と記載条件への案内が付いています。目当ての人物を見つけたら、そのまま条件を確かめられます。

人物図鑑を埋める

人物図鑑に載るのは79人です。決まった場所で話しかける、決まった場面を見る、 イベントをクリアするなど、条件は人物ごとに違います。

  • 人物図鑑の記載条件 … 79人ぶんの条件と、クリアするだけで条件を満たすイベント、満たしたつもりで満たせていない場面
