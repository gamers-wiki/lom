ドラゴンキラー編

カテゴリ：イベント攻略全5イベント

竜帝ティアマットに仕えるドラグーンのラルクと、そのラルクを追跡するシエラを中心に、3体の知恵のドラゴンを狩る物語。奈落の入口にある墓石を調べるところから始まり、ノルン山脈、骨の城、白の森でドラゴンを倒したあと、ティアマットの城である焔城での決戦まで、5つのイベントで構成されます。

紅き堕帝

紅き堕帝
日記No.41
発生条件仲間にNPCがいない状態で、奈落の入口にある墓石を調べる
ランド奈落
仲間になる人物ラルク
入手AF『骨のカンテラ』、AF『壊れた人形』

進め方

  1. 墓石を調べると奈落へ落ち、ラルクとの会話になる。会話中の質問はどちらを選んでもよいが、一緒に下層へ降りることを拒んでいる間は先へ進まない。承諾するとラルクが仲間になる。
  2. 奈落を管理する賢人オールボンの管理室へ向かう。この時点では管理室以外のほとんどの扉が閉まっているので、迷わず着ける。
  3. オールボンから炎の洗礼を受ける許可をもらい、炎の洗礼の間で赤いシャドールに話しかけて洗礼を受ける。これで奈落のすべての扉が開く。
  4. 下層へ進む。無言の四面宮①に入ろうとするとラルクに力を試すと言われ、「良い」と答えると四面宮①へ移動してゼーブル・ファーとのバトル。もう少し探索したいなら「良くない」と答える。
  5. 勝つと場面が変わり、ティアマットが現れる。3匹の竜を倒してほしいと頼まれる。ティアマットへの質問はどちらを選んでも同じ返答になる。
  6. 依頼を引き受けるとアーティファクトをもらってクリア。断った場合は、もう一度ティアマットに話しかけて引き受ければよい。

ボス

ゼーブル・ファー（無言の四面宮①）。四面宮①に入ると後戻りできない。

イベント発生中は奈落の地下最上層に釜焚きのシャドールがおらず、地上へ戻る手段がない。クリアまで奈落からは出られない。

オールボンの管理室にいるシャドールは、炎の洗礼の間か地下最上層（選択肢では「地上」と表示）へテレポートさせてくれる。ただし、このイベント進行中に限り地下最上層へのテレポートは使えない。

ゼーブル・ファー戦のあと依頼を引き受けるまでの間はラルクが仲間から外れているので、彼と会話ができる。

進行中に探索できる範囲は限られている。奈落をすべて見てまわるならクリア後に。クリア後はラルクが奈落・不気味な墓石に現れ、奈落への出入りが自由になる（無言の四面宮①の奥へも行ける）。

群青の守護神

群青の守護神
日記No.38
発生条件ラルクを仲間にした状態でノルン山脈に入る
ランドノルン山脈
関連NPCラルク、シエラ（仲間にできない）
入手AF『竜骨』、AF『魔導書』

進め方

  1. ラルクを連れてノルン山脈へ。何者か（シエラ）に襲われる場面のあと、風の集落へ向かう。
  2. ラルクを連れて風の集落を訪れると、登山道の入口に風読み士の三元老が現れる。話しかけると登山道に入れるようになる。
  3. 山道を登る途中、各所で三元老が勝負を挑んでくる。山陰の死角、雲望のまほろば、万代の山景にいる三元老をそれぞれ倒すと封印が解ける。
  4. 3つの封印をすべて解いてから、登山道⑧にある風読み士の石像に触れると石像が消え、山頂への道が開く。
  5. 山頂でメガロードとのバトル。勝つとラルクからアーティファクトをもらってクリア。

ボス

メガロード（ノルン山脈・山頂）。知恵のドラゴンのうちの1体。

登山道⑧の石像に、封印を解く前に触れるとふもとの山林へ戻されてしまう。3人の三元老を倒してから触れること。

AF『竜骨』はこのときにしか手に入らない。

ラルクがいない状態で風の集落に入ると、登山道の入口には風読み士の石像が置かれていて、触れるとふもとの山林へ戻される。三元老の場面を見たあとでも、ラルクを外すと入口は再び石像で塞がれる。登山道に入るなら必ずラルクを連れていく。『真紅なる竜帝』のクリア後は、ラルクがいなくても登山道に入れる。

風の集落にいる風読み士の台詞は、進行状況とラルクの有無で変わる。

クリア後、ラルクを連れているときのみ風の集落の石像がなくなり、登山道⑧の石像はなくなる。

紫紺の怨霊

紫紺の怨霊
日記No.39
発生条件『課外活動』クリア後、ラルクを仲間にした状態で骨の城・ガイコツ門に入る
ランド骨の城
関連NPCラルク、シエラ（仲間にできない）
入手AF『滴る緑の杖』

進め方

  1. ラルクを連れてガイコツ門に入るとイベント発生。現れるガイコツ戦士に「立ち去らない」と答えるとバトルになる。勝てばガイコツ戦士は二度と現れず、城内へ入れる。「立ち去る」と答えてしまったら、画面を切り替えれば再び現れるので選び直す。ガイコツ門は頭ガイコツの鼻先あたりを調べると開く。
  2. 1階にある3つのスイッチのどれかに、パーティーが3人いる状態で触れるとトラップが作動し、地下1階へ落とされる。これは進行に必要なので、必ず引っかかること。
  3. 地下1階で仲間とはぐれるので、まず合流する。ペットまたはゴーレムは地下1階のあばら部屋⑤、ラルクは2階のあばら部屋⑩にいる。各所にいる番人のガイコツに話しかけると隣の部屋への道が開く。
  4. 3階の昇降装置前でシエラに襲われる。退けると近くの床に鍵が落ちている。あばら部屋⑨でラルクが閉じこめられた部屋を守る番人だけは、この鍵がないと道を開けてくれない。
  5. 全員と合流したら、3階の死の桟橋で不死皇帝、その奥のムクロ玉座でジャジャラとのバトル。ジャジャラは一度倒すと復活し、そのまま第2形態との戦いになる。
  6. ジャジャラ（第2形態）を倒すとアーティファクトをもらってクリア。

ボス

シエラ（3階の昇降装置前）、不死皇帝（死の桟橋）、ジャジャラ→ジャジャラ第2形態（ムクロ玉座。連戦）。

パーティーが3人いないとトラップが作動せず、イベントが進まない。発生前に『ペット牧場』か『ゴーレム作成』をクリアして、ペットかゴーレムを用意しておくこと。

骨の城では各階の移動を昇降装置で行う。イベント発生中に限り、昇降装置の扉を開けるのに地下1階では2人、1階では3人が必要（2・3階の扉は主人公ひとりでよい）。人数を揃えてから昇降装置前のスイッチのどれかに触れると扉が開く。一度トラップが作動したあとは、1階のスイッチを押しても落とされない。

クリア後は骨の城の城内へ自由に出入りでき、ひとりで昇降装置の扉を開けられる。『真紅なる竜帝』クリアまで、死の桟橋で不死皇帝第2形態と一度だけ戦える。

白妙の竜姫

白妙の竜姫
日記No.37
発生条件ラルクを仲間にした状態で白の森に入る
ランド白の森
関連NPCラルク、シエラ（仲間にできない）
入手AF『サンゴの燭台』（巨木の台座に着いたときにラルクから受け取る）

進め方

  1. ラルクを連れて白の森を進む。発生中でラルクがいるときのみ、画面を切り替える直前に進む方向についてラルクが助言してくれることがある。「こっちから、アイツの香りがしている」と言う方向へ進めば巨木の台座に着く。「道を外れたようだ」と言われたら、ひとつ前のマップに戻って正しい道を探す。案内どおりでなくても台座には行ける。
  2. ラルクを連れて巨木の台座に着くと、ラルクとシエラの会話になる。このあとラルクは AF『サンゴの燭台』を渡して仲間から外れる。
  3. そのままヴァディスとシエラの2体同時のバトル。
  4. 両方を倒すとクリア。

ボス

ヴァディス＋シエラ（巨木の台座。同時に出現）。直前にラルクが外れるので必ずNPC抜きで戦うことになり、負けてコンティニューしてもすぐバトルが始まるため装備の変更などができない。巨木の台座へ行く前に準備を済ませておく。シエラは倒したまま長くバトルを続けていると戦闘不能が解除されて復帰するが、ヴァディスは先に倒しても復帰しない。長引きそうならヴァディスを重点的に攻めるとよい。

進行中に2回ほど出る選択肢は、どちらもストーリーや攻略手順に影響しない。

クリア後、ラルクは奈落の入口に現れなくなる。奈落の入口の墓石を調べると、以降は同じマップにシエラが現れる。

真紅なる竜帝

真紅なる竜帝
日記No.40
発生条件『白妙の竜姫』クリア後、シエラを仲間にした状態で奈落・第1層①に入る
ランド奈落、焔城
仲間になる人物シエラ（連れていないと進行しない）
関連NPCラルク（仲間にできない）
入手なし

進め方

  1. 奈落の入口に現れたシエラを仲間にして奈落に入るとイベント発生。
  2. 奈落の底へ向かう。第4層①でシャドールに落としてもらうと簡単に着ける。
  3. 奈落の底で会話のあと、鉄巨人ラルクとのバトル。
  4. 倒すと奈落が焔城へ置きかわる。このときシエラが自動的に仲間から外れるので、焔城の入口にいるシエラをもう一度仲間にする。シエラがいないと焔城には入れない。
  5. 焔城内の落とし穴を解除しながら5階を目指す。1階④、2階③、地下1階⑥で起こるバトルに勝って珠を解放すると、その珠の色に対応した落とし穴が作動しなくなる。5階への最短手順は次のとおり。
    1. 入口から上へ進み、MAP26-16へ。
    2. MAP26-16で左下、MAP26-25で左上の通路を進む。
    3. MAP26-35で落とし穴に落ちる。
    4. MAP26-30で一番左の階段を進む。
    5. MAP26-5でスカイドラゴンとバトル。
    6. 来た道を戻り、MAP26-30で一番右の階段を進む。
    7. MAP26-32で落とし穴に落ちる。
    8. MAP26-23でランドドラゴンとバトル。
    9. 部屋の右にある通路から出て、MAP26-18で左上、MAP26-16で左下、MAP26-25で右下の通路を進む。
    10. MAP26-14でゼノアとバトル。
    11. 右上の扉に入ってまっすぐ上へ進み、MAP26-36へ。
  6. 5階でティアマットとのバトル。倒せばドラゴンキラー編クリア。シエラは仲間から外れ、焔城は奈落に戻る。

ボス

鉄巨人ラルク（奈落の底）、スカイドラゴン（焔城 1階④）、ランドドラゴン（地下1階⑥）、ゼノア（2階③）、ティアマット（5階）。鉄巨人ラルク戦は負けてコンティニューしても装備変更などができないまま再戦になるので、奈落の底へ行く前に準備しておく。

シエラを仲間から外すとイベントが進まない。外してしまったら奈落の入口に戻ってもう一度仲間にする。

鉄巨人ラルクを倒してからクリアまでは奈落に入れない。また、一度焔城に入るとクリアまで外へ出られない。入念に準備してから入ること。

シエラが焔城の入口に現れるのは、焔城が出現している間だけ。

クリア後、ラルクは奈落・不気味な墓石に、シエラは白の森・巨木の台座に現れる。ラルクを連れていなくてもノルン山脈・風の集落の石像がなくなり、山頂でメガロードと何度でも戦えるようになる。
