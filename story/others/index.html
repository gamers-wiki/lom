その他のイベント

カテゴリ：イベント攻略全4イベント

どの編にも属さない単独の4イベントです。ミンダス遺跡でティーポを探す『危険なアフタヌーンティー』、ゴミ山の人形たちと戦う『災いを呼ぶ人形』、デュマ砂漠でサハギンのテイクに協力する『震える砂』、ボンボヤジの逃げたゴーレムを連れ戻す『ボンボヤジの研究室』で、それぞれ別のランドで起こります。

危険なアフタヌーンティー

危険なアフタヌーンティー
日記No.12
発生条件ミンダス遺跡に入る
ランドミンダス遺跡
入手瓶詰の精霊、さびたイカリ

進め方

  1. 遺跡の入口でドゥエルに会い、ティーポがはぐれたことを知る。
  2. 遺跡の扉はカギ花人を操作して開閉する。扉は東の扉（MAP11-6）と西の扉（MAP11-11）に4枚ずつあり、交差した道をふさいでいる。地下の建造物の入口を開けるまでの最短の手順は次のとおり。
    1. MAP11-10で上の花人を右へ動かす
    2. MAP11-12で下の花人を右へ動かす
    3. MAP11-14で念力花人に話しかける
    4. MAP11-12で下の花人を左へ動かす
    5. MAP11-17で花人に話しかける
  3. 巨大建造物前（MAP11-17）から地下の建造物に入る。扉を開けるには、繁栄の跡⑧（MAP11-14）の念力花人に話しかけたあと、建造物の入口付近の花人に話しかける。
  4. 建造物の最深部でティーポを見つけると鳩血鬼とのバトルになる。勝つとアーティファクトを入手してクリア。
途中で分からなくなったら遺跡の入口に戻る。扉の開閉が最初の状態に戻るので、やり直せる。別のルートでも建造物の扉は開けられる。
  • 手順3の前に繁栄の跡④（MAP11-5）側から東の扉（MAP11-6）に入ると、なげいているティーポの姿が見えるが、ここでは連れ戻せない。
  • 建造物の内部に入れるのは、このイベントか『彷徨の回廊』の発生中だけ。

ボス

鳩血鬼。建造物の最深部でティーポと話したあとに現れる。

発生中はドミナの町のマークの部屋からティーポがいなくなる。ティーポとの会話が進行に必要なイベントは、これをクリアするまで進められない。

クリア後は建造物の入口の扉が閉まり、MAP11-14の念力花人は念力を送ってくれなくなる。

災いを呼ぶ人形

災いを呼ぶ人形
日記No.19
発生条件ゴミ山に入る
ランドゴミ山
入手魔導書、月読の鏡

ゴミ山の構造

ゴミ山は同じ場所に地形の少し違うマップが2枚ずつあり、ここでは仮にAパーツ・Bパーツと呼びます。通常は今いるマップと同じパーツのマップへ移動しますが、ゴミ山の中に4か所ある特定の地点を通ったときだけ、移動先でパーツが入れ替わります。掘り出し産地はAパーツにしかなく、ボンボヤジの研究室とルーイの部屋はBパーツにしかありません。

進め方

  1. ゴミ山に入ると人形たちのささやきが聞こえ、少女の人形が去っていく。
  2. 掘り出し産地を目指す。入口から最短で行くルートは MAP13-1→13-2→13-4→13-6→13-8→13-9→13-10→13-11。入口のAパーツにいるびっくり箱から聞けるルートと同じ。
  3. 掘り出し産地でのバトルに勝つとアーティファクトが手に入り、そのままルーイの部屋でルーイとの会話になってクリア。

人形が教えてくれる目印（掘り出し産地までにたどるおもちゃの順番）は次のとおり。

  • 入口のびっくり箱（Aパーツ）：びっくり箱→クマのぬいぐるみ→人形→びっくり箱→木馬
  • 入口のびっくり箱（Bパーツ）：木馬→人形→びっくり箱→木馬
  • ルーイの部屋のルーイ：ルーイの部屋→ガラクタの丘→クマのぬいぐるみ→人形→びっくり箱→木馬

びっくり箱のワープ

ガラクタの丘のびっくり箱に話しかけると、返事の選択肢によっては入口のAパーツへ飛ばされます。飛ばされる選択肢は回数ごとに変わり、1回目「遠ざかる」、2回目「笑い飛ばす！」、3回目「命はいつか消えるもの」、4回目以降「入口へ飛ばしてもらう」です。3回飛ばされたあとに入口のAパーツのびっくり箱に話しかけるとルーイの部屋へ飛ばされ、以降このびっくり箱はいなくなります。

クリア後はゴミ山・入口①（MAP13-1）に花人が現れ、話しかけるとボンボヤジの研究室へテレポートできる。

震える砂

震える砂
日記No.66
発生条件デュマ砂漠の木のマナレベルを3にし、『シュタインベルガー』と『星に願いを』をクリア（または失敗・消滅）したあと、デュマ砂漠・南側①（MAP9-2）に入る
ランドデュマ砂漠
仲間になる人物テイク（イベント中のみ）
『フローライト』の発生中に夢のなかのデュマ砂漠で南側①に入っても条件を満たしたことにならない。ワールドマップから入ったデュマ砂漠で行う。

進め方

  1. 南側①で仲間にいじめられているサハギンのテイクに話しかけ、会話中の選択肢で「よし！ 倒そう！」を選んで仲間にする。
  2. テイクを連れて、MAP9-2→9-3→9-7→9-6→9-4→9-17 の順に進む。正しい道を選ぶとテイクが「キーマの地震を感じるデポ」と言うので目安にする。
  3. 東側②（MAP9-17）の流砂が消えるので、砂大河②（MAP9-20）に入り、東側④（MAP9-23）へ進む。
  4. キーマとのバトルに勝つと、とげとげの種とひらたい種が手に入る。
  5. 直後にテイクから種をゆずってほしいと頼まれる。どちらかを答えるとクリア。テイクは仲間から外れ、東側②の流砂は元に戻る。

ボス

キーマ。東側④（MAP9-23）でテイクとともに戦う。

テイクについて

  • 次の状態ではテイクを仲間にできない：ペットかゴーレムを連れている／『ペット牧場』をクリアしていない／ペット牧場がペットでいっぱい。
  • デュマ砂漠から出るとテイクは自動的に仲間から外れ、経験値は0、レベルは1に戻る。仲間にいないときは必ず南側①（MAP9-2）にいて、話しかければまた仲間にできる。
  • いったん砂漠から出ると流砂が復活し、ルートを最初からやり直すことになる。
  • 最後の返答で「これで良かったら！」を選ぶと2つの種は失うが、イベント後に南側①に現れるテイクをペットにできる。「そう思うことがダメ」を選ぶと種は残るが、テイクを二度とペットにできない。
  • クリアするとMAP9-20〜9-23には二度と行けなくなる。拾い忘れのアイテムがないか確かめてからキーマに挑む。

ボンボヤジの研究室

ボンボヤジの研究室
日記No.60
発生条件ゴミ山・ボンボヤジの研究室にいるボンボヤジに話しかけ、「なんとかしてやる」と答える
ランドゴミ山、キルマ湖

進め方

  1. ボンボヤジから、逃げ出したマシンゴーレムのパブロフをなんとかしてほしいと頼まれる。
  2. キルマ湖へ行く。居場所は占い師のメイメイからヒントを聞けるが、聞かなくても進められる。
  3. キルマ湖の入口でマシンゴーレムに話しかけ、そのあとを追って南の森①（MAP5-2）へ行く。
  4. マシンゴーレムとのバトルに勝つと、自動的にゴミ山での会話に移ってクリア。アーティファクトの入手はない。

ボス

マシンゴーレム（パブロフ）。キルマ湖・南の森①で戦う。

クリア後は、ボンボヤジの研究室で武器・防具・楽器の売買（ほかのセーブデータの主人公とのやりとり）ができるようになる。パブロフは研究室に、ルーイセンヨウパブロフはルーイの部屋に現れ、話しかけると特定の場所へテレポートできる。作成小屋のエントランスに入ろうとすると『ゴーレム作成』が発生する。
