宝石泥棒編

カテゴリ：イベント攻略全10イベント

珠魅の騎士・瑠璃と、そのパートナーである真珠姫を中心に、珠魅の核を狙う宝石泥棒サンドラを追う物語。ドミナの町の酒場で瑠璃と出会うところから始まり、メキブの洞窟、レイリスの塔、魔法都市ジオを経て、煌めきの都市での最終決戦まで、10のイベントで構成されます。

まいごのプリンセス

まいごのプリンセス
日記No.5
発生条件メキブの洞窟に入る
ランドドミナの町、メキブの洞窟
関連NPC瑠璃、真珠姫（どちらも仲間にできない）
入手AF『石の目玉』、AF『蛍袋のランプ』
失敗・消滅レイリスの塔に入ると失敗。『ホワイトパール』を発生させると消滅

進め方

  1. ドミナの町の酒場で瑠璃と話す。「何があったのか聞く」→「仲間のことを聞く」→「一緒にその仲間を探す」の順に選ぶと瑠璃が仲間になり、同時にレイチェルから AF『ヒスイの卵』を受け取れる。
  2. 『ヒスイの卵』でメキブの洞窟を出現させ、中に入るとイベント発生。瑠璃が仲間にいなくても、卵さえあれば進められる。
  3. 洞窟の最深部（地底大空洞）まで進むと、ドゥ・インクとのバトルになる。
  4. 倒すと真珠姫が現れ、瑠璃との会話になる。会話中の選択肢はどれを選んでも展開は変わらない。真珠姫からアーティファクトを受け取るとクリア。瑠璃を連れていた場合は、ここで仲間から外れる。

ボス

ドゥ・インク。大型のサル型モンスターで、地底大空洞で襲ってくる。

『ヒスイの卵』は『幸せの四つ葉』のクリア報酬としても手に入るが、その時点ではこのイベントはもう発生しない。このイベントを見たいなら、レイリスの塔に入る前に、必ずドミナの町の酒場でレイチェルからもらうこと。

瑠璃を仲間にする別ルートもある。酒場で上記以外の選択肢を選ぶか、ニキータを連れている場合は、ドミナバザールから町マップへ出て瑠璃と再度話す。「連れていく」を選べば仲間になる。「断る」を選んだ場合も、仲間にNPCがいなければ仲間になり、NPCがいれば酒場で瑠璃に話しかけて「一緒に探す」→「一緒に行く」を選ぶと仲間になる。

メキブの洞窟には、ぷにゅに塞がれて先へ進めない場所が2か所ある。この奥へは、本イベントをクリアするか、一度レイリスの塔に入ったあとでないと行けない。

クリア後（失敗・消滅を含む）は、瑠璃がドミナの町の酒場に出なくなり、メキブの洞窟の2体のぷにゅは本体と尻尾の位置が入れかわる。

岩壁に刻む炎の道

岩壁に刻む炎の道
日記No.23
発生条件断崖の町ガト・門前町のショップ前にいる修道女（または草人）に話しかける。『波間に眠る追憶』の発生中は起きない
ランド断崖の町ガト
入手AF『数秘術の石板』、AF『サンゴの燭台』

進め方

断崖の町ガトだけで完結するイベント。ガトが舞台になるイベントの中では必ず最初に発生する。中盤まではとにかく草人を追いかけて話しかけることで進む。

  1. テラスで草人（または修道女）に話しかける。
  2. 寺院の礼拝堂で修道女か草人に話しかける。
  3. 再びテラスで草人（または修道女）に話しかける。
  4. 寺院の礼拝堂で倒れている修道女に話しかける。
  5. テラスへ行く。修道女の正体が宝石泥棒サンドラだとわかり、ルーベンスが核を奪われる。
  6. 寺院の礼拝堂前でボイド警部からサンドラ捜索を頼まれる。ここで出る選択肢はどちらを選んでも、結局サンドラを捜すことになる。瑠璃か真珠姫を連れていると、選択肢なしで捜索が始まる。
  7. ダンジョン（断崖の修験の道）を抜けて滝側へ向かう。入ったら一番左の洞窟へ入り、洞窟内を右へ進み、出たら左へ進むと早い。イベント発生中は落ちている葉っぱが道しるべになる。
  8. カンクン鳥の巣でサンドラを見つけると、ボイド警部からアーティファクトをもらってクリア。

手前の人物をすり抜けることがあり、そのときだけ後ろの人物に話しかけられる。「草人（または修道女）」と書いたのはそのため。

ダンジョンにはサンドラ捜索の依頼を受けてから入れる。それより前は修道女が道を塞いでいる。

クリア後は断崖の町ガトのダンジョンへ自由に出入りでき、ダンジョンを通らずに寺院側と滝側を行き来できるようになる。

波間に眠る追憶

波間に眠る追憶
日記No.28
発生条件港町ポルポタ・ホテル内ロビーで右側の白いモティさんに話しかけ、選択肢を選ぶ（どちらでもよい）。『岩壁に刻む炎の道』の発生中は起きない
ランド港町ポルポタ
入手AF『海賊のカギ爪』、AF『瓶詰の精霊』

進め方

バトルが一切ないイベント。町の人への聞き込みだけで進む。

  1. ホテルのロビーでモティさんと話すと、幽霊騒ぎの解決を頼まれる。「幽霊に強いやつ」として主人公とボイド警部のどちらを勧めても、主人公が引き受ける流れになる。
  2. 入り江で衛兵トーマに話しかける。
  3. ホテル入口に現れたザル魚君に話しかける。
  4. ポルポタハーバーにいるボイド警部にくり返し話しかけ、「ボイド警部の事を聞く」を出して選ぶ。（2〜3は順不同。会話中の選択肢はどれでもよい）
  5. もう一度ボイド警部に話しかけると、「青い瞳」に心当たりがないか聞かれる。
  6. ホテルのラウンジでザル魚君かトーマに話しかける。帝国船沈没の真相が語られた直後に青い瞳が盗まれ、モティさんからアーティファクトを受け取ってクリア。

イベント発生中、ホテルのロビーや入口で画面を切り替えるたびに帝国兵の亡霊が出るが、話しかけることはできない。

進行には関係ないが、このイベントをクリアするか、発生中にショッピングマリーナの花屋に話しかけると、人魚のフラメシュがショッピングマリーナに出るようになる。

クリア後はホテル内ラウンジにザル魚君、入り江に衛兵トーマが現れる（『プッツィを探せ！』でプッツィが入り江にいる間は出ない）。トーマは一度話すとラウンジへ移動する。

ホワイトパール

ホワイトパール
日記No.21
発生条件瑠璃を仲間にしていない状態で、レイリスの塔・双子鳥の門にいる真珠姫に話しかける
ランドレイリスの塔
仲間になる人物瑠璃、真珠姫（どちらも仲間にしなくても進行できる）
関連NPCレディパール（仲間にできない）
入手AF『とけない心』、AF『海賊のカギ爪』

進め方

  1. レイリスの塔・双子鳥の門で真珠姫と話す。「一緒に行く」を選ぶと真珠姫が仲間になる。「とめる」を選ぶと、運命の扉の前に瑠璃が現れ、そこで「つきあう」を選ぶと瑠璃が仲間になる。
  2. 11階の大きな扉を開けて、最上階の運命の部屋へ向かう。運命の部屋へは、8階と10階をつなぐ昇降装置を使わないと着けない。昇降装置は中央のスイッチに下から触れるか、調べると動く。
  3. 運命の部屋で会話のあと、塔の番人デスペインとのバトル。
  4. 倒すと瑠璃が駆けつける。瑠璃を連れているか仲間が誰もいない場合は真珠姫が仲間になり、瑠璃以外のNPCを連れている場合はそのNPCのまま進む。
  5. 塔を降りて1階から出ようとすると、サンドラの予告状とともにジュエルビースト2が襲ってくる。
  6. 倒すとサンドラが退却し、アーティファクトを受け取ってクリア。真珠姫を仲間にしていた場合は、ここで仲間から外れる。

ボス

デスペイン（運命の部屋）、ジュエルビースト2（塔の1階）。デスペイン戦は負けてコンティニューを選んでも、メニューを開けないまま再戦になる。運命の部屋に入る前に装備や回復の準備を済ませておくこと。

真珠姫を仲間にできるのは、イベント発生時か運命の部屋でのデスペイン戦直後の会話だけ。発生時に仲間にしたあと別れてしまうと、運命の部屋までは真珠姫なしで進むしかない。

このイベントを発生させると、瑠璃はドミナの町の酒場からいなくなる。イベント中は条件を満たしていても酒場には現れない。

クリア時に真珠姫が仲間にいるかどうかでアーティファクトを渡す人物が変わるが、もらえるものは同じ。

幸せの四つ葉

幸せの四つ葉
日記No.31
発生条件下の「発生させるまで」を参照
ランドドミナの町、魔法都市ジオ、マイホーム
仲間になる人物エメロード
関連NPC瑠璃、真珠姫（どちらも仲間にできない）
入手AF『ヒスイの卵』
失敗・消滅魔法都市ジオ・フルーツパーラーに入ったときに『ギルバート・愛の出席簿』が発生する状況、同イベントの発生中、『夢の檻の中へ』の発生中は発生しない

発生させるまで

  1. 『岩壁に刻む炎の道』『波間に眠る追憶』『ホワイトパール』の3つをクリアする。
  2. マイホームに入る。
  3. ドミナの町の酒場で瑠璃を仲間にし、酒場から出るときの会話で選択肢を何度か選んで、真珠姫をマイホームへ移動させる。
  4. 魔法都市ジオの町マップに入る。
  5. エメロードが魔法学園③にいるときに話しかける。
  6. 4〜5のあと、エメロードが図書室にいるときに話しかけ、出てきた選択肢のどれかを選ぶ。

4〜6は瑠璃を仲間にした状態で行う。4と5は順不同。エメロードの居場所は曜日で変わる。

曜日エメロードの居場所
ジン、サラマンダー、ドリアード、アウラ魔法都市ジオ・魔法学園③
ウンディーネ、ノーム魔法都市ジオ・図書室

瑠璃は手順3より前はドミナの町の酒場、3以降は魔法都市ジオの宝石店にいる。

進め方

  1. 発生後、瑠璃を連れた状態で教室→図書室の順にエメロードと話し、騎士役を引き受けるとエメロードが仲間になる。
  2. 3つの核を集める。順番は自由で、途中の選択肢はどれを選んでもよい。
    • 美術品講堂に入り、美術品倉庫でディアナと話す。
    • メフィヤーンスがいないときに学園長室へ入り、選択肢を選ぶ。メフィヤーンスはドリアード曜日や特定のイベント発生中だけ学園長室を空ける。
    • 宝石店に入る、喫茶店でカウンター内から量産型ティーポと話す、上の2つの核を手に入れる、の3条件を満たしてから町マップへ移動し、喫茶店に入って選択肢を選ぶ。
  3. 核が揃うと予告状が届き、美術品倉庫でディアナに頼まれて闘技場へ飛ばされる。ジュエルビーストとのバトル。
  4. 勝つとアーティファクトが手に入り、マイホームへ場面が移ってクリア。

ボス

ジュエルビースト（闘技場）。

エメロードを仲間にすると、クリアまで魔法都市ジオから出られない。曜日を進めたいときは喫茶店に泊まる。またこの間は瑠璃を仲間にできず、闘技場での対戦もできない。ディアナに闘技場へ飛ばされたあとも、クリアまで闘技場からは出られない。
クリア後は真珠姫がマイホームの居間からいなくなる。

コスモ

コスモ
日記No.24
発生条件『幸せの四つ葉』クリア後、瑠璃を仲間にしていない状態でマイホームの自宅前へ行き、瑠璃に「来てない」→「一緒にさがす」の順で答える
ランドマイホーム、メキブの洞窟
仲間になる人物瑠璃（発生時に必ず加入）、レディパール（仲間にしなくても進行できる）
関連NPC真珠姫（仲間にできない）
入手なし

進め方

  1. 自宅前で瑠璃と話して発生させる。それまでにメキブの洞窟へ入ったことがないと、瑠璃は自宅前に現れない。別の選択肢を選んでしまっても、画面を切り替えれば同じ場所に瑠璃が再び現れる。
  2. 発生時に瑠璃が必ず仲間になるが、すぐ外しても問題なく進められる。
  3. マイホームを出るとサンドラの予告状が届き、メキブの洞窟へ向かう。瑠璃を連れていれば、洞窟内のダックや草人から真珠姫たちの行き先を聞ける。
  4. 地下1階⑥にいる宝石王には、最低1回は話しておく。話していないと、奥へ進んでも真珠姫たちが現れない。会話中の選択肢はどちらでもよい。
  5. 地下2階⑦に入ると会話が始まる。瑠璃を連れていた場合は自動的にレディパールへ入れかわり、仲間がいなかった場合は必ずレディパールが仲間になる。瑠璃以外のNPCを連れていた場合はそのまま。
  6. ジュエルビースト3とのバトル。勝つと地下2階⑦での会話になり、レディパールがいればここで仲間から外れる。
  7. サンドラとレディパールが去ったあと、倒れている瑠璃かその横の宝石王に話しかけると、場面がマイホームに移ってクリア。

ボス

ジュエルビースト3（メキブの洞窟・地下2階）。

クリア後、瑠璃はマイホームの寝室のベッドに横たわる。この間、ベッドでのセーブはできない。

『サボテン』発生前で、バドがマイホームの居間で倒れていた場合は、クリアで病気が治る。

月読の塔の誘惑者

月読の塔の誘惑者
日記No.22
発生条件『コスモ』クリア後、「マイホームの寝室で瑠璃と話す」「寝室から出る」を瑠璃がいなくなるまでくり返し、そのあとレイリスの塔・双子鳥の門で瑠璃を仲間にする
ランドマイホーム、レイリスの塔
仲間になる人物瑠璃、レディパール（仲間にしなくても進行できる）
関連NPC真珠姫（仲間にできない）
入手なし

進め方

  1. 『コスモ』クリア後、瑠璃はマイホームの寝室のベッドにいる。「ベッドで寝ている瑠璃に話しかける（返答が「……」だけのときは数えない）」と「寝室から出る」を合計6回以上行うと、瑠璃が寝室からいなくなる。会話中の選択肢はどちらでも進む。
  2. レイリスの塔の入口（双子鳥の門）で瑠璃を仲間にして、塔を登る。運命の部屋へのルートは『ホワイトパール』と同じ。
  3. 運命の扉は中の人物を知る者しか開けられず、瑠璃には開けられない。
  4. 運命の部屋に入ると会話になり、真珠姫から瑠璃を助けてほしいと頼まれる。「助ける」を選ぶと瑠璃が、「断る」を選ぶとレディパールが仲間になり、塔の1階で仲間にならなかったほうと戦う。
  5. 運命の部屋から出ると自動的に1階へ移動する。敵になったNPCを倒せば、会話のあとクリア。仲間のNPC（瑠璃かレディパール）は仲間から外れる。

ボス

瑠璃またはレディパール（塔の1階）。運命の部屋でどちらを選んだかで相手が変わるが、どちらを選んでもクリアできなくなることはなく、その後の展開にも影響しない。

イベント発生後は、瑠璃をレイリスの塔の入口で仲間にできる。発生中は瑠璃を連れた状態でしか塔の建物内に入れない。

運命の部屋を出ると自動的に1階へ戻されるので、塔の中を探索したいなら、運命の部屋に入る前に済ませておく。

クリア後、一度マイホームに入ると、ドミナの町の酒場に瑠璃と真珠姫が現れる。

アレクサンドル

アレクサンドル
日記No.32
発生条件『月読の塔の誘惑者』クリア後に一度マイホームへ入り、ドミナの町の酒場で瑠璃に話しかけて「引き受ける」を選び、真珠姫を仲間にする
ランドドミナの町、魔法都市ジオ
仲間になる人物真珠姫
関連NPC瑠璃（仲間にできない）
入手なし

進め方

バトルなしで進むイベント。真珠姫を連れた状態でないと進められない。

  1. ドミナの町の酒場で瑠璃の頼みを引き受け、真珠姫を仲間にする。
  2. 魔法都市ジオの美術品倉庫へ行くと、ディアナが石になっている。石になったディアナを調べたときの選択肢は、どちらを選んでも展開は変わらない。
  3. 3つの心の鍵を集める。順番は自由。
    • 学園長室の机の上
    • 楽器の店のテーブルの上
    • 城門の前
  4. 心の鍵が揃っても、直接ディアナの像へは行けない。美術品講堂でクリスティーから話を聞くと、闘技場にディアナの像が現れる。
  5. 闘技場でディアナの像を調べるとクリア。真珠姫は仲間から外れる。
心の鍵は真珠姫を仲間にしているときにしか出ない。真珠姫を外してしまった場合は、ドミナの町の酒場でもう一度仲間にすること。

心の鍵をすべて手に入れると、クリアまで闘技場からドゥエルがいなくなり、闘技場を使えない。

クリア後、真珠姫はドミナの町の酒場に現れなくなる。

フローライト

フローライト
日記No.29
発生条件『星に願いを』をクリア（失敗・消滅でも可）し、『アレクサンドル』をクリアしたあと、魔法都市ジオ・宝石店に入る
ランド魔法都市ジオ、デュマ砂漠（夢の中）
関連NPC瑠璃、真珠姫、レディパール（いずれも仲間にできない）
入手なし

進め方

  1. 宝石店に入ると自動的に宝石箱パンドラへ移動し、蛍姫と夢魔少女ベルに出会う。ベルへの自己紹介は3択だが、変わるのは彼女の返答だけ。
  2. ベルとの会話で「はい」を選ぶと夢の中へ、「いいえ」を選ぶと宝石店へ移動する。最初だけはどちらを選んでも夢の中へ行く。
  3. 夢の中のデュマ砂漠で、西側⑥を目指す。最初は西側③が流砂で塞がれているので、次の順で消す。
    1. 西側①に入り、瑠璃とレディパールの会話を見たあと瑠璃と話す（西側①の流砂が消える）。
    2. 西側③に入り、瑠璃とレディパールの会話を見る。
  4. 西側⑥でレディパールとサンドラの会話を見ると、ジュエルビースト4とのバトル。
  5. 勝つと宝石箱パンドラに戻り、クリア。

ボス

ジュエルビースト4（夢の中のデュマ砂漠・西側⑥）。

クリア前に夢から出ると流砂が復活し、夢に入るたびに流砂を消す手順を最初からやり直すことになる。

一度夢の中に入ってからでないと、宝石店には戻れない。宝石店に入ると自動でパンドラへ飛ばされる状況では、アレックスが店からいなくなる。宝石箱から戻ってきたときにはいるので、買い物はそのときに。

夢の中のデュマ砂漠は地形と敵配置は通常と同じだが、オアシスにポポイ像がない、砂漠の外へ出ると宝石箱パンドラへ戻される、さまざまな人物が登場する、といった違いがある。各所にいるニキータに200ルク払うと、砂漠内の特定のマップへ順番にワープできる。

クリア後、デュマ砂漠の西側①と西側③の流砂はなくなる。

ティアストーン

ティアストーン
日記No.33
発生条件下の「発生させるまで」を参照
ランドドミナの町、魔法都市ジオ、煌めきの都市
仲間になる人物瑠璃または真珠姫（どちらか一方を必ず仲間にする）
関連NPCレディパール（特定のバトルでのみ真珠姫と入れかわる）
入手なし

発生させるまで

  1. 『フローライト』と『小さな魔法使い』をクリアする。
  2. ドミナの町の教会前でボイド警部と話し、「そんなことはない」を選ぶ。
  3. ボイド警部の頼みを「引き受ける」。
  4. 魔法都市ジオの宝石店を出ようとする。
  5. 宝石店内の右下にある宝石箱を調べる。

2と3以外の場面では、選択肢はどれを選んでもよい。

進め方

  1. 宝石箱パンドラで蛍姫からレディパールの話を聞き、瑠璃か真珠姫のどちらかを仲間にする。煌めきの都市に入る前なら普通に別れることもでき、その場合はもう一度パンドラに入ってどちらかを仲間にすればよい。真珠姫を仲間にしてから瑠璃と話したときだけ、運命の剣が手に入る。
  2. 蛍姫にもらった AF『玉石の王杓』で煌めきの都市を出現させ、最上階の玉石の座を目指す。
  3. 各階のサフォーの門を開けながら上へ進む。門の開け方は下の「サフォーの門」を参照。
  4. 玉石の座に入るには、ルーベンスの部屋と煌めき廊⑦で珠魅の幻を見ておく必要がある。
  5. 玉石の座で宝石王とのバトル。勝てば宝石泥棒編クリア。仲間のNPC（瑠璃か真珠姫）は仲間から外れる。

サフォーの門

  1. 瑠璃か真珠姫を連れた状態で門を調べる。
  2. 直後に出るジュエルビースト（2〜4）を倒す。
  3. 周囲の台座すべてに鍵となる宝石をセットしてから門を調べる。

宝石は7種類あり、各宝石の部屋にひとつずつ置かれている。すべての台座に宝石をセットして門を調べると、正解の宝石がセットされている数だけ音が鳴る。正解の組み合わせはプレイのたびに変わるので、音を手がかりに組み合わせを絞り込む。組み合わせさえ合っていれば、どの台座にどれを置くかは問わない。階を上がるごとに台座がひとつずつ増え、一度使った種類の宝石をまた使うこともある（使った宝石は対応する宝石の部屋で再入手できる）。

ボス

ジュエルビースト2〜4（各階のサフォーの門）、宝石王（玉石の座）。ジュエルビースト戦と宝石王戦では、真珠姫を連れている場合のみレディパールに入れかわる。

瑠璃か真珠姫を連れて煌めきの都市に入ると、クリアまで外へ出られない。煌めきの都市ではセーブもできない。入る前に準備を済ませておくこと。

クリア後は煌めきの都市に自由に出入りできるようになり、宝石屋もできる。煌めき廊⑦に瑠璃（ジン曜日以外は真珠姫も）が現れ、ジン曜日のみ玉石の座にレディパールが現れる。ディアナ、ルーベンス、エメロード、蛍姫は煌めきの都市へ移る。

ボイド警部はドミナの町・風なびく草原の教会に現れる（一度話すといなくなる）。サラマンダー曜日にドミナの町の酒場で『シャドウゼロをつかまえろ！』ができるようになる。
