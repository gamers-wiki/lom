海賊vs穴掘り団編

カテゴリ：イベント攻略全7イベント

バーンズ率いる海賊ペンギンと、コンゴ率いる穴掘り団の宝争いに巻き込まれるイベント群。キルマ湖で海賊たちに出会うところから始まり、以降は海賊船バルドの操舵室から船を動かして各地の宝を探しに行く。『石の魚』から『プッツィを探せ！』までの7イベントで構成される。

海賊船バルドの操舵

このイベント群の多くは、海賊船バルドの操舵室にいるラムティーガーに話しかけ、船を決まった位置まで動かすと発生する。海は東西5列（西からA〜E）、南北5行（北から1〜5）の25マスで、ランドに入った直後の船はC3にいる。方角を1回指示するごとに1マス進み、端は反対側の端につながっている（E3で東へ進むとA3に出る）。移動のたびにラムティーガーがひとこと言うので、現在地の確認に使える。

ABCDE
1つかれたね戦闘A『宝の地図』
2『南海の砂浜』戦闘A
3START
4つかれたね戦闘B『静かなる海域』
5『雪原の妖精』戦闘B
  • イベント名のマスは、発生条件を満たした状態で入るとそのイベントが始まる。
  • 戦闘のマスに入ると船尾上甲板①で戦闘になり、終わると操舵室の入口に戻される。戦闘Aはガルフィッシュ3体とシージャック1体、戦闘Bはガルフィッシュ3体とスペクター1体。
  • 「つかれたね」のマスでは問いかけがあり、「もういい」と答えると船の位置をそのままにして船内を歩き回れる。

C3から戦闘・イベントのマスを通らずに各目的地へ向かう指示の並びは次のとおり。

目的地イベント指示の並び
E4『静かなる海域』東 → 東 → 南
D1『宝の地図』北 → 北 → 東
B5『雪原の妖精』東 → 南 → 南 → 東 → 東 → 東（D3・D4・D5・E5・A5を経由）
A2『南海の砂浜』西 → 西 → 北
B5は隣のB4とC5がどちらも戦闘マスなので、A5側から入る。西回り（西→西→南→南→東）のほうが短いが、途中のA4で「つかれたね」の問いかけが入る。

石の魚

石の魚
日記No.10
発生条件キルマ湖の入口で、バーンズか海賊ペンギンに話しかける
ランドキルマ湖
入手アーティファクト『蛍袋のランプ』『獣王のメダル』

進め方

  1. キルマ湖の入口でバーンズか海賊ペンギンに話しかける。ペンギンに話しかけた場合は選択肢が出るが、どちらを選んでも展開は同じ。
  2. 南の湖岸③（MAP5-7）でカメのトートに話しかける。ここの選択肢もどちらでもよい。
  3. 湖面を見渡せる崖→崖の下の順に進む。
  4. 崖の下で湖のヌシ、ゲイザーと戦う。勝つとアーティファクトを入手してクリア。

ボス

ゲイザー。

  • キルマ湖に入ってからこのイベントをクリアするまでは、海賊船バルドに入っても強制的に追い出される。
  • クリア後、トートは湖面を見渡せる崖に移る。キルマ湖の各所に妖精が現れ、ペンギン像はなくなる。

砂浜のメモリー

砂浜のメモリー
日記No.27
発生条件マドラ海岸に入る
ランドマドラ海岸
入手アーティファクト『さびたイカリ』『月読の鏡』

進め方

  1. マドラ海岸の入口でデイビッドとヴァレリの会話を見る。ヴァレリが去り、デイビッドが追いかける。
  2. 海岸を右へ進み、キングスケイブ③（MAP12-15）へ向かう。
  3. 襲ってくるフルメタルハガーを倒す。自動的にクイーンズケープでのデイビッドたちの会話に移る。
  4. ヴァレリに話しかけるとクリア。マップから出てもクリアになるが、その場合はアーティファクトが手に入らない。

ボス

フルメタルハガー。

クリア前に必ずヴァレリに話しかけること。話しかけずにマップを出るとアーティファクトを取り逃がす。
  • マドラ海岸の各所に出る破裂するカニは、このイベントとは関係ない。
  • 入口から左へ行った先にいるぷにゅの向こうへは、この段階では進めない。
  • クリア後、クイーンズケープのカニと話すとワールドマップへ移動させられる。

静かなる海域

静かなる海域
日記No.34
発生条件海賊船バルドの操舵室でラムティーガーに話しかけ、船をE4へ移動させる
ランド海賊船バルド
入手アーティファクト『獣王のメダル』『とけない心』

海賊船バルドの中だけで進行し、途中で船から出ることもできない。このイベントの発生中は、ほかのイベントをクリアできない。

進め方

  1. 無風地帯で船が止まる。釣りをしていたペンギンが、釣り上げたビンから幽霊を解き放ってしまう。
  2. 船尾楼甲板から出る。
  3. 船尾楼甲板で海賊ペンギンと話す。
  4. 船長室でバーンズと話す。ビンに封印し直せばよいと助言される。
  5. 船倉でタルを調べ、「美人のお姉さんがいるぞ！」を選ぶ。
  6. 転がるタルを調べてビンを手に入れる。
  7. 船尾上甲板に上がるとゴーヴァとの戦闘になる。勝つとバーンズからアーティファクトをもらい、クリア。

ボス

ゴーヴァ。

発生中はラムティーガーに話しかけても船を動かせず、バーンズに話しかけて船を降りることもできない。操舵室から始まるほかのイベントも発生させられないので、事実上、クリアするまで船に閉じ込められる。
クリア後、マイホームの書斎にカニが現れる。

宝の地図

宝の地図
日記No.35
発生条件「『まいごのプリンセス』をクリアする」「レイリスの塔へ入ったあとにメキブの洞窟に入る」のどちらかを満たしたあと、海賊船バルドの操舵室でラムティーガーに話しかけて船をD1へ移動させ、バーンズの問いに「はい」と答える
ランド海賊船バルド、メキブの洞窟
失敗・消滅地図を持ち去られたあと、破片をすべて取り返す前にメキブの洞窟から出ると失敗。アナグマのいるマップに入ってから規定時間内に破片を奪うか画面を切り替えないと、コンゴに洞窟から追い出されて失敗

進め方

  1. 航海中にメキブの洞窟へ着く。船長室でバーンズから、洞窟にあるという宝の地図を一緒に探そうと誘われる。「はい」と答えると洞窟に場面が移る。
  2. 地下1階③（MAP4-13）へ行き、穴掘り団を見る。
  3. 地下1階⑥（MAP4-16）に落ちている宝の地図を調べる。アナグマたちが現れ、地図を8つの破片にして持ち去る。
  4. 洞窟内を走り回るアナグマから破片を奪い取る。話しかけると3割ほどの確率で奪える。奪えなかったときは、その場に1〜2秒足止めされる。
  5. 8つすべて奪うと海賊船バルドへ移動し、クリア。バーンズからお礼の品をもらう。

時間制限

アナグマのいるマップに入ると、画面には表示されない時間の計測が始まる。規定時間までに破片を奪うか画面を切り替えないと、コンゴが現れて洞窟から追い出され、失敗になる。規定時間はそれまでに奪った破片の数で決まり、破片を奪うたびに新しい規定時間で計り直される。

地下1階⑥（MAP4-16）だけは、規定時間を過ぎてもコンゴが現れない。ここのアナグマを最後に回すと楽になる。
  • このイベント用の人物が洞窟に配置されるのは、操舵室で船をD1へ動かして入ったときだけ。発生中にワールドマップからメキブの洞窟に入ってもイベントは進まない。
  • この状態のメキブの洞窟から出ると、海賊船バルドに戻る。
  • クリア後（失敗した場合も）、マイホームの書斎にカニが現れる。

雪原の妖精

雪原の妖精
日記No.51
発生条件『宝の地図』をクリアし、『こおれる過去』をクリアまたは失敗したあと、海賊船バルドの操舵室でラムティーガーに話しかけて船をB5へ移動させ、バーンズの問いに「はい」と答える。『宝の地図』を失敗していると発生しない
ランド海賊船バルド、フィーグ雪原

進め方

  1. 船長室でバーンズから、雪原に眠るという宝を探すよう頼まれる。「はい」と答えると自動的にフィーグ雪原へ移る。
  2. ペンギンたちは寒さでリタイアし、ひとりで探索する。最初に出会う下級妖精のフィオレンティナから、秘宝は第7階級の妖精エアラングが持っていると聞き、第2階級の妖精が見えるおまじないをかけてもらう。
  3. 雪原の各所にいる妖精におまじないをかけてもらい、見える階級を上げていく。
  4. ラクラレシュから第7階級が見えるおまじないを受け、エアラングと話す。ドラウプニルを受け取ってクリア。船に戻ってバーンズに報告する。

妖精視力とおまじない

  • 妖精視力の数値以下の階級の妖精だけが見える。最初の妖精視力は1。
  • 妖精におまじないをかけてもらうと、妖精視力はそのおまじないのLVと同じ数値になる。
  • おまじないをかけてもらえるのは、今の妖精視力と同じ階級の妖精からだけ。
  • 妖精視力が7のときにエアラング以外の妖精と話すと、妖精視力が6に戻る。
  • 雪原から出ると妖精視力は1に戻る。
  • 名乗らない妖精もいる。

最短で進めるなら、次の順におまじないをかけてもらう。

  • フィーグ雪原に妖精が現れるのは、操舵室で船をB5へ動かして入ったときだけ。この状態の雪原から出ると、ワールドマップではなく海賊船バルドに戻る。
  • クリア後、マイホームの書斎にカニが現れる。

南海の砂浜

南海の砂浜
日記No.52
発生条件『たゆたう歌声』クリア後、ミニゲーム『カニバッシング』でカニを20匹以上踏んだあと、海賊船バルドの操舵室でラムティーガーに話しかけて船をA2へ移動させ、バーンズの問いに「はい」と答える
ランド海賊船バルド、マドラ海岸
失敗・消滅マドラ海岸のクイーンズケープで宝箱を調べて穴掘り団が現れたあと、アナグマに対して「何もあげない」を選ぶと失敗

最後の選択以外で失敗することはないので、何度でも挑戦できる。

進め方

  1. 船がマドラ海岸に着く。バーンズに呼ばれ、海岸にあるという宝を探すよう頼まれる。「はい」と答えると自動的にマドラ海岸へ移り、アナグマたちが現れている。
  2. 穴掘り団が先に来ている。バーンズからアナグマを買収する資金として、ホロニック金貨15枚を受け取る。
  3. 入口から右へ進むと、アナグマが道をふさいでいる。上から3番目のアナグマに金貨を渡すといなくなる。
  4. 奥でもアナグマが通路をふさいでいる。別のアナグマとの物々交換で手に入れた桜貝の小瓶やプカシェルを渡して買収しながら進む。
  5. クイーンズケープ（MAP12-14）で宝箱を調べると、背後からコンゴが現れる。選択肢に出るいずれかの品をアナグマに渡すとクリア。何も渡さないと失敗。
  6. 船長室でバーンズに報告し、お礼の品を受け取る。

アナグマの買収と物々交換

  • 右回りに動き続けるアナグマに金貨を渡すと桜貝の小瓶がもらえる。左右にしか動かないアナグマに桜貝の小瓶を渡すとプカシェルがもらえる。
  • どちらも所持数は表示されないが、同時に複数個持てる。
  • MAP12-9でプカシェルと交換するために、MAP12-5で桜貝の小瓶を1つ余分にもらっておく。
マップ交換でもらえるもの通路をふさぐアナグマを買収するもの

MAP12-13桜貝の小瓶、プカシェルプカシェル
  • ホロニック金貨は毎回15枚渡される。使い切ると海賊船バルドに戻され、最初からやり直しになる。
  • 最後の選択で「何もあげない」を選ぶと失敗する。選択肢にある3品をすべて持っていれば、この選択肢は出ない。
  • クリアでも失敗でも、イベントが終わる直前にアーティファクトの代替品がもらえる。
  • この状態のマドラ海岸から出ると海賊船バルドに戻るが、操舵室で船をA2へ動かせばまた訪れられる。
  • クリア後（失敗した場合も）、マイホームの書斎にカニが現れる。

プッツィを探せ！

プッツィを探せ！
日記No.4
発生条件海賊船バルドに入ったあと、ウルカン鉱山の穴掘り団アジトに入る
ランドウルカン鉱山、海賊船バルド、港町ポルポタ
失敗・消滅『豆一族を探せ！』と『ディドルいやになる』をクリアまたは失敗したあと、ドミナの町に入ると消滅

発生させると、ほかのイベントの進行に制限がかかることが多い。発生させたらすぐにクリアするのがよい。

進め方

  1. 穴掘り団アジトで、海賊ペンギンたちがプッツィを連れ去る。コンゴに捜索を押しつけられる。
  2. 海賊船バルドの船倉①（MAP20-22）にあるタルを調べる。プッツィが飛び出して逃げていく。
  3. 港町ポルポタの入り江にいるプッツィに話しかけるとクリア。
  • 発生条件の「海賊船バルドに入ったあと」には、海賊が留守の間に入って追い出された場合も含む。
  • 『ポキール・夢への誘い』の発生中に行ける夢のウルカン鉱山でアジトに入っても発生しない。現実のウルカン鉱山なら、『ポキール・夢への誘い』の発生中でも発生する。
  • はじめてキルマ湖に入ってから『石の魚』をクリアするまでは、海賊たちが留守で海賊船バルドに入れず、このイベントが進まなくなる。こうなったら『石の魚』をクリアするしかない。
  • 発生すると穴掘り団アジトからコンゴの詩集がなくなり、コンゴを呼び出せなくなる。プッツィを救出したあとはコンゴが常にアジトにいるが、彼に話しかけても、コンゴと話すことが手順になっているイベントは進められない。
  • プッツィが港町ポルポタの入り江にいる間は、入り江にほかの人物が現れない。入り江の人物と話す手順があるイベントは、クリアするまで進まない。
