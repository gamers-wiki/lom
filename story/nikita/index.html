ニキータ編

カテゴリ：イベント攻略全6イベント

行商人ニキータの商売に付き合わされるイベント群。ドミナの町のバザールでニキータに話しかけるところから始まり、『ニキータ商い道中』から『ニキータ・最後の商い？』までの5本が順につながる。外伝にあたる『シュタインベルガー』を加えた6イベントで構成される。

ニキータ商い道中

ニキータ商い道中
日記No.1
発生条件ドミナの町のドミナバザールでニキータに話しかけ、質問に「いいえ」→「はい」の順に答えて仲間にする
ランドドミナの町、リュオン街道
仲間になる人物ニキータ
入手アーティファクト『炎』『獣王のメダル』

進め方

  1. ドミナバザールでニキータを仲間にする。リュオン街道の盗賊退治を頼まれる。
  2. ドミナの町にあるマークの部屋（武器屋）でティーポに話しかけ、アーティファクト『車輪』を受け取る。
  3. 『車輪』でリュオン街道を出現させ、奥へ進む。
  4. ローラントサイド台地で盗賊たちに会い、呼び出されたマンティスアントと戦う。
  5. 戦闘後、ニキータがアイテムを売りつけてくる。アーティファクトを受け取るとクリア。仲間にしていたニキータはここで離脱する。

ボス

マンティスアント。

  • ニキータを一度離脱させても、ドミナバザールに行けば仲間にし直せる。『車輪』を受け取ったあとは、ニキータを連れていなくてもイベントを進められる。
  • ローラントサイド台地でボロンに通行税を要求されるが、「出す」「出さない」のどちらを選んでも所持金やアイテムは減らない。
  • 戦闘後にニキータから買わされる品（草ムシまんじゅう、ヘバタのタコムシ、アダマソナベ）の代金は300ルク。所持金が足りなければ持っている分だけ取られ、0ルクなら無料で受け取れる。あとから請求されることはない。
  • リュオン街道の最初の分かれ道にいるダナエは、このマップに一度入るとドミナの町の宿屋1階に移動する。話しかけなくても進行に影響はない。
  • 『危険なアフタヌーンティー』の発生中はティーポがマークの部屋におらず、そのイベントをクリアするまで『車輪』を受け取れない。
  • 『もう1人の自分』の発生後、ドミナバザールで自分の影を見てからそのイベントをクリアするまでの間も、ティーポから『車輪』を受け取れない。
  • このイベントを進めないとリュオン街道が出現しない。

続・ニキータ商い道中

続・ニキータ商い道中
日記No.45
発生条件『岩壁に刻む炎の道』クリア後、断崖の町ガトのショップでニキータを仲間にする
ランド断崖の町ガト
仲間になる人物ニキータ
入手アーティファクト『壊れた人形』『獣王のメダル』、草ムシまんじゅう、500ルク
失敗・消滅断崖の町ガトの滝に入る前にニキータを仲間から外すと失敗

進め方

  1. 断崖の町ガトのショップでニキータを仲間にする。草ムシ集めに付き合うことになる。
  2. 大カンクン鳥の巣の近くにある滝へ行く。ダンジョンを通らずに行けるので道中は短い。
  3. 滝で妖精を出現させ、話しかける。ニキータとの会話に移り、品物とアーティファクト、500ルクを受け取ってクリア。
妖精は、滝のマップに入ってすぐには現れない。一度別のマップへ出てから滝に戻り、画面を切り替えずに15秒ほど待つと出現する。
  • イベント発生中に滝のマップへ入るとニキータは仲間から外れ、クリアするまで寺院の方向へは戻れなくなる。
  • 『流れ行くものたち』クリア後から『ポキール・夢への誘い』発生前までは、同じ場所に別の妖精も出現するが、話しかけられるのはイベント用の妖精だけ。
  • クリア後（失敗した場合も）、ニキータは月夜の町ロアの宝石屋に現れる。

続々・ニキータ商い道中

続々・ニキータ商い道中
日記No.46
発生条件『危険なアフタヌーンティー』と『続・ニキータ商い道中』をクリアまたは失敗したあと、月夜の町ロアの宝石屋でニキータを仲間にする
ランド月夜の町ロア、ミンダス遺跡
仲間になる人物ニキータ
失敗・消滅ニキータを仲間から外すと失敗

進め方

  1. 宝石屋でニキータを仲間にする。念力を使う花人に会いたいと言われる。
  2. ミンダス遺跡へ行き、扉のカギになる花人を動かしながら、念力使いの花人がいる繁栄の跡⑧（MAP11-14）を目指す。扉の仕組みと道筋は『危険なアフタヌーンティー』と同じ。
  3. 念力使いの花人はテレポートで逃げてしまう。あきらめて入口へ引き返す。
  4. 帰り道はカギ花人の数が減っている。残っている花人を次の順に動かすと入口まで戻れる。
    1. MAP11-16で、下の花人を右へ動かす
    2. MAP11-12で、下の花人を左へ動かす
    3. MAP11-10で、上の花人を左へ動かす
  5. ミンダス遺跡の入口まで戻るとクリア。ニキータは離脱し、いなくなっていたカギ花人は元に戻る。
マップ残っている花人位置
MAP11-7男下
MAP11-10男上
MAP11-12女下
MAP11-16男下
MAP11-25女上、下
  • 『続・ニキータ商い道中』が終わると宝石屋にニキータが現れるが、『危険なアフタヌーンティー』を未クリアの間は話しかけても仲間にならない。
  • 仕掛けは『危険なアフタヌーンティー』と共通だが、このイベントでは地下の建物に入れない。
  • クリア後（失敗した場合も）、ニキータは魔法都市ジオのフルーツパーラーに現れる。

続々々・ニキータ商い道中

続々々・ニキータ商い道中
日記No.47
発生条件『鍛冶屋ただいま閉店中』と『続々・ニキータ商い道中』をクリアまたは失敗したあと、魔法都市ジオのフルーツパーラーでニキータを仲間にする
ランド魔法都市ジオ、ウルカン鉱山
仲間になる人物ニキータ
失敗・消滅ニキータを仲間から外すと失敗

進め方

  1. フルーツパーラーでニキータを仲間にする。仕入れた品をワッツに売りに行くと言われ、ウルカン鉱山のワッツの店へ向かう。
  2. ワッツの店に入ると、ニキータが店内に何かを置いていったん外へ出る。
  3. 再び店に入る。ニキータが代金を取り立てようとし、ワッツからはワニ革を持ってくるよう言われる。
  4. ワニ革を手に入れ、持った状態でワッツの店に入って渡す。いったん店を出る。
  5. もう一度店に入るとクリア。ニキータは離脱する。

ワニ革の入手方法

ワニ革の入手手段は次の5つ。あらかじめ持っていれば、ワッツの店に何度か続けて入るだけで終わる。

  • ドミナの町の宿屋にいるユカちゃんからもらう。ワッツに「持ってこい」と言われたあと、ワニ革を1つも持っていないときだけ。このイベントの発生中しか使えない。
  • ウルカン鉱山の穴掘り団アジトでアナグマから買う。アジトで詩集を読んでコンゴを出現させ、コンゴ→アナグマ→もう1匹のアナグマの順に話しかけると500ルクで売ってくれる。こちらも「持ってこい」と言われたあとから有効で、このイベントが終わったあとも使える。ただし『プッツィを探せ！』か『ギルバート・愛の履歴書』の発生中は使えない。
  • 『ディドルの手紙』クリア時にディドルからもらう。
  • ティラノスが落とす戦利品から拾う。
  • 『リング・りんぐ・ランド』で手に入れる。
  • 『続々・ニキータ商い道中』が終わるとフルーツパーラーにニキータが現れるが、『鍛冶屋ただいま閉店中』を未クリアの間は仲間にならない。
  • クリア後（失敗した場合も）、ニキータはフルーツパーラーからいなくなる。

ニキータ・最後の商い？

ニキータ・最後の商い？
日記No.48
発生条件『続々々・ニキータ商い道中』をクリアまたは失敗したあと、魔法都市ジオの美術品講堂に入る
ランド魔法都市ジオ、港町ポルポタ、断崖の町ガト
仲間になる人物ニキータ

進め方

  1. 魔法都市ジオの宮殿で、クリスティーたちの会話を立ち聞きする。
  2. 港町ポルポタの入り江で、記憶を失ったニキータを仲間にする。
  3. ニキータを連れて魔法都市ジオのクリスティーのもとへ行く。
  4. そのまま断崖の町ガトのカンクン鳥の巣→クリスティーの宮殿→カンクン鳥の巣の順に移動する。ニキータが巣から落ちて仲間から外れる。
  5. 港町ポルポタの入り江でニキータをもう一度仲間にするとクリア。

このイベントの発生中、ニキータは次のような扱いになる。

  • 港町ポルポタの入り江に出現する。
  • ほかのNPCを連れていると仲間にできない。
  • 『プッツィを探せ！』でプッツィを海賊船から逃がしている場合、そのイベントをクリアするまで入り江に現れない。
  • ドミナの町に入ると仲間から外れる。

クリア後は、いつでもニキータを仲間にできるようになる。ニキータはフルーツパーラーに現れる。

シュタインベルガー

シュタインベルガー
日記No.42
発生条件魔法都市ジオのフルーツパーラーにいるバーテンと話したあと、ニキータを仲間にしていない状態で、断崖の町ガトの洞窟内部㉑（MAP6-44）にいる修道女のどちらかに話しかける
ランド断崖の町ガト、魔法都市ジオ、月夜の町ロア、デュマ砂漠

ニキータ編のなかでは外伝にあたり、ニキータを仲間にしていなくても進められる。

進め方

  1. 断崖の町ガトの断崖の修験の道⑨（MAP6-43）で、酒を盗み飲んだニキータと戦う。
  2. 魔法都市ジオのフルーツパーラーでバーテンと話す。
  3. 月夜の町ロアの悪魔のぼったくり亭でマスターに話しかけ、「はい」→「わかる」と選んで心に樽を受け取る。
  4. デュマ砂漠のオアシスへ行く。自動的に断崖の町ガトの醸造所へ移り、クリアとなる。

ボス

ニキータ。

ニキータを仲間にした状態で醸造所に入ると追い返される。
