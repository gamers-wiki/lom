ディドル編

カテゴリ：イベント攻略全3イベント

大道芸人コンビのカペラとディドルをめぐるイベント群。ドミナの町の噴水公園から姿を消したディドルを、相棒のカペラとともに探すところから始まる。『ディドルの手紙』『ディドルいやになる』『ディドルさらわる』の3イベントで構成され、毎回ディドルがどこかへ行ってしまう。

ディドルの手紙

ディドルの手紙
日記No.6
発生条件下記の手順を踏む
ランドドミナの町、リュオン街道
入手ワニ革

発生させる手順

発生させるまでに少し手間がかかる。3以降はすべてドミナの町で行う。

  1. 『ニキータ商い道中』と『小さな魔法使い』をクリアする。
  2. マイホームの居間に入る。
  3. 女神の使いの噴水公園でディドルに話しかける。
  4. いなか道に入る。
  5. 女神の使いの噴水公園でカペラと話す。
  6. 商店街にいる草人から、鳥のことは鳥に聞くようにという話を聞く。
  7. 宿屋に入り、カペラたちの会話を見る。
  8. いなか道でカペラと話す。
『もう1人の自分』の発生中は草人の会話が専用のものになり、6の条件を満たせない。その場合は『もう1人の自分』をクリアするしかない。

進め方

  1. いなか道で郵便ペリカンと話す。宛名のない郵便物を街道に捨てたことがわかる。郵便ペリカンは、イベント発生後に一度画面を切り替えると現れる。
  2. リュオン街道の分かれ道②（MAP3-8）に手紙が落ちている。調べるとカペラが来て読み始める。ここで出る選択肢はどれを選んでも展開に影響しない。ぷにゅを使うとすぐに着ける。
  3. ボロンの洞窟の入口近くにいるディドルに話しかける。カペラが手紙を返し、ディドルから手紙を読まなかったかと尋ねられる。「本当は読んだ」と答えるとディドルが洞窟に入っていくので、そのまま追いかける。
  4. ボロンの洞窟の最深部でギガレックスと戦う。勝つとディドルからワニ革をもらい、クリア。

ボス

ギガレックス。

  • ディドルへの返事は「本当は読んだ」が早い。「本当は読んでいない」と嘘をつくと2人は帰っていき、追ってリュオン街道の入口まで戻ると会話が起きて、結局ボロンの洞窟まで引き返すことになる。遠回りになるだけで利点はない。
  • リュオン街道へ行く前に、いなか道の郵便ペリカンと話しておくのを忘れないこと。
  • もらったワニ革は、『続々々・ニキータ商い道中』で使えるので取っておくとよい。
クリア後、カペラとディドルは月夜の町ロアの悪魔のぼったくり亭に移る。

ディドルいやになる

ディドルいやになる
日記No.20
発生条件『紅き堕帝』と『ディドルの手紙』をクリアしたあと、月夜の町ロアの悪魔のぼったくり亭にいるカペラに話しかけてから町マップへ行き、もう一度悪魔のぼったくり亭に入る。『真紅なる竜帝』の発生中は発生しない
ランド月夜の町ロア、マイホーム、奈落
失敗・消滅奈落の無言の四面宮③（MAP10-37）でポキールに話しかけ、「戻る」を選ぶと失敗

進め方

  1. 月夜の町ロアの酒場でカペラに話しかける。
  2. マイホームからワールドマップに出る。月夜の町ロアへ向かうシャドールを見かける。
  3. 月夜の町ロアの酒場に入る。
  4. 月夜の町ロアの町マップへ行く。ディドルが見つかった直後、シャドールに連れ去られる。
  5. 奈落に入る。ディドルたちの会話のあと、自動的に奈落の底に落とされる。
  6. 奈落の底から無言の四面宮②（MAP10-30）を目指す。途中にいるシャドールに触れると底へ戻されるので、避けながら上へ進む。
  7. 無言の四面宮②でディドルたちの会話のあと、マミーエイプと戦う。勝つとクリア。

ボス

マミーエイプ。

シャドールは、底へ戻されるたびに数が減っていく。なかなかたどり着けないときは、わざと何回か戻されるのも手。
  • 奈落の底に落とされてからクリアまたは失敗するまで、底にポキールがいる。「戻る」を選ぶとワールドマップに出られるが失敗になる。「戻らない」を選んだあとはセーブができる。
  • ディドルがさらわれてからクリアまたは失敗するまで、奈落の入口にラルクが現れず、仲間にできない。
  • 奈落に入ったときの会話は、『真紅なる竜帝』クリア後だと省略される。
  • クリア後（失敗した場合も）、カペラとディドルは悪魔のぼったくり亭からいなくなる。
  • 奈落の底に落とされたあとは、クリアか失敗するまで奈落から出られない。
  • 『白妙の竜姫』をクリアしていると奈落の底に落とされず、イベントが進まなくなる。進めるには『真紅なる竜帝』をクリアする必要がある。
  • ポキールにセーブ目的で話しかけるとき、誤って「戻る」を選ばないこと。

ディドルさらわる

ディドルさらわる
日記No.16
発生条件『豆一族を探せ！』と『ディドルいやになる』をクリアまたは失敗したあと、ドミナの町の聖マナ教会講堂でコンゴと話してから、ドミナの町の女神の使いの噴水公園に入る
ランドドミナの町、白の森

ディドル編の最後のイベント。白の森のアナグマの切り抜け方さえわかれば、あとは目的地を目指すだけ。

進め方

  1. 教会を占拠した穴掘り団（コンゴ）と話す。白の森を掘り返す前に人員を増やしたいらしい。
  2. 噴水公園に入ると、アナグマが現れてディドルをさらっていく。
  3. 白の森へ行き、アナグマの妨害をかわしながら西の森④（MAP22-17）を目指す。
  4. 西の森④でディドルたちの会話のあと、ハンプティデーモンと戦う。勝つとクリアで、白の森からアナグマがいなくなる。

ボス

ハンプティデーモン。この戦闘では、コンティニュー後に装備を変更できない。挑む前に装備を整えておく。

アナグマの切り抜け方

このイベントの発生中だけ、白の森の入口（MAP22-1）、北の森③（MAP22-4）、西の森③（MAP22-16）にアナグマが現れる。これらの場所から特定のマップへ行こうとすると、アナグマに別のマップへ運ばれてしまう。

  • アナグマは話しかけると気絶するが、数秒で目を覚ます。そのマップのアナグマが全員気絶している間に画面を切り替えれば通れる。
  • 画面を切り替える前にアナグマが起きてしまうなら、先にアナグマを1か所に集める。アナグマの進路上に立つと移動を妨害できるので、こちらの望む方向以外への移動をすべて妨害して集めていく。次のマップに近い場所に集めるとよい。
  • アナグマのいるマップを通るのが距離的には最短だが、遠回りして避けることもできる。ただし西の森③（MAP22-16）だけは必ず通ることになる。
マップアナグマの数移動を阻止されるマップ気絶している時間
MAP22-11匹MAP22-35秒
MAP22-42匹MAP22-55秒
MAP22-164匹MAP22-178秒
穴掘り団が登場するほかのイベントと同時に発生させても共存できる。先に発生させていたイベントが失敗になることはない。
