バド＆コロナ編

カテゴリ：イベント攻略全4イベント

双子の魔法使い、バドとコロナをめぐるイベント群。ドミナの町のカボチャ騒ぎで2人と出会い、弟子として自宅に住み着いたあとの出来事が続く。『小さな魔法使い』『賢人を探せ！』『お父さんのほうき』『サボテン』の4イベントで構成される。

小さな魔法使い

小さな魔法使い
日記No.2
発生条件『ニキータ商い道中』か『まいごのプリンセス』のどちらかをクリアしたあと、自宅から出る
ランドマイホーム、ドミナの町
関連する人物バド、コロナ（どちらもこのイベント中は仲間にできない）

進め方

  1. 自宅を出ると郵便ペリカンが騒いでいる。ドミナの町でカボチャが大量発生したことを知る。
  2. ドミナの町の町はずれへ行く。バドとコロナが占拠しており、2人との戦闘になる。
  3. 勝つとバドが弟子入りを申し出てくる。返事をするとクリア。

ボス

バド＋コロナ。

  • 弟子にするかどうかの選択は、マイホームに移ったバドとコロナとの最初の会話の内容が変わるだけ。どちらを選んでもクリア後は2人が居間に現れ、仲間にできるようになる。

賢人を探せ！

賢人を探せ！
日記No.62
発生条件『小さな魔法使い』クリア後、コロナを仲間にしていない状態でマイホームの居間にいるバドに2回話しかけ、誘いに「はい」と答える
ランドマイホーム、リュオン街道ほか各地
仲間になる人物バド
失敗・消滅失敗になることはない

進め方

  1. 居間のバドから、6人の賢人に会いたいと頼まれる。バドを連れて出発する。
  2. ガイア、トート、ポキール、ロシオッティ、オールボン、セルヴァの6人を訪ね、それぞれから助言をもらう。
  3. 全員と話したあと、バドを連れたままマイホームに入るとクリア。バドは仲間から外れる。全員と話したあとにバドと別れてもクリアになる。
  • 賢人に話しかけるときは、必ずバドを仲間にしておく。
  • 賢人には自分から話しかけること。ほかのイベント中に起こる自動の会話では助言をもらえない。

賢人の居場所

早い時期に発生させられるが、6人全員に会うにはゲームをかなり進める必要がある。少しずつ進めればよい。

賢人居場所条件・注意
ガイアリュオン街道・大地の顔ガイア最初からいる
トートキルマ湖・南の湖岸③（MAP5-7）／湖面を見渡せる崖『石の魚』を発生させると南の湖岸③に現れる。一度話してから画面を切り替えるといなくなり、以後は湖面を見渡せる崖にいる
ポキール月夜の町ロア・明月の路地『精霊の光』クリア後に出現。一度ここに入ったあと町のマップへ出るといなくなる
奈落・無言の四面宮③（MAP10-37）『ディドルいやになる』でディドルを追って奈落に落ちてから出現。同イベントをクリアまたは失敗するといなくなる
ウルカン鉱山・入口／ワッツの店ワッツの店には、ウルカン鉱山の出現後から『鍛冶屋ただいま閉店中』のクリアまでいる。入口には『流れ行くものたち』クリア後、エスカデを仲間にしていないときだけ現れ、『ポキール・夢への誘い』をクリアまたは失敗するといなくなる
マナの聖域・マナの木①（MAP27-2）必ずいる
ロシオッティジャングル・ロシオッティの座最初からいる。ただし、『獣王』でヘイソンから変な獣の話を聞くところまで進めるか、同イベントを消滅させるまで、または『獣王』を失敗したあとに『うごめく森』をクリアするまでは話しかけられない
オールボン奈落・オールボンの管理室最初からいる。焔城が出現している間は奈落に入れない
セルヴァ断崖の町ガト・断崖の道バドがセルヴァ以外の5人と話したあとに出現
ルシェイメア・腐乱小路⑥（MAP24-9）／落つる山脈⑤（MAP24-20）必ずいる。ただしルシェイメアには『上天の光』の発生中しか入れない
ポキールは居場所が変わりやすい。確実に会うならマナの聖域へ行く。

お父さんのほうき

お父さんのほうき
日記No.18
発生条件『賢人を探せ！』を発生させ、『災いを呼ぶ人形』をクリアしたあと、コロナを仲間にしていない状態でいったんマイホームから出て、居間にいるバドかコロナに話しかける（『サボテン』の影響でバドが倒れている間は発生しない）
ランドマイホーム、ゴミ山
関連する人物バド（仲間にしなくても進行できる）、コロナ（仲間にできない）
失敗・消滅上の発生条件を満たす前に、「出現しているランドが18以上」と「宝石泥棒編・エスカデ編・ドラゴンキラー編のいずれかをクリア」の両方を満たすと消滅

進め方

  1. 自宅に戻ると、父親の形見のほうきがなくなったとコロナが騒いでいる。
  2. 2階の寝室でサボテン君に話しかける。コロナのほうきを捨ててきたことがわかり、コロナが家を飛び出す。
  3. コロナを追ってゴミ山の掘り出し産地へ向かう。行き方は『災いを呼ぶ人形』のときと同じ。
  4. 掘り出し産地でコロナに追いつく。コロナを逃がした直後、グレムリンが襲ってくる。
  5. グレムリンを倒すと自動でマイホームに戻り、クリア。

ボス

グレムリン。

  • 寝室でのサボテン君との会話の最後に日記の選択肢が出るが、イベントの展開には関係ない。
  • 発生中はバドとコロナのセリフが変わり、普段のように話しかけて仲間にすることはできない。バドだけは、コロナを追ってゴミ山へ出発する直前に一度だけ仲間にできる。ここで断るか、仲間にしてから別れると、発生中はもう仲間にできない。
  • バドを仲間にしていた場合、クリア時に離脱する。クリア後は2人とも居間に戻り、仲間にできる。
  • クリア後、ゴミ山の入口にいる花人の念力テレポートの行き先に「ルーイの部屋」が加わる。
  • 発生条件を満たしても、なかなか発生させずにいると消滅することがある。条件がそろったら早めに発生させる。
  • 居間のバドかコロナに話しかければ発生する状態まで進むと、サボテン君が寝室からいなくなり、サボテンくん日記を書いてもらえない。イベントを発生させれば戻ってくる。

サボテン

サボテン
日記No.49
発生条件下記の手順を踏む（『お父さんのほうき』の発生中は発生しない）
ランドマイホーム、ドミナの町、リュオン街道、ジャングル、魔法都市ジオ、海賊船バルド
関連する人物バド（仲間にできない）、コロナ（仲間にしなくても進行できる）
失敗・消滅バドが倒れてから『サボテン』が発生するまでの間に『コスモ』をクリアすると、バドの病気が治って消滅

発生させる手順

  1. 『小さな魔法使い』をクリアする。
  2. 魔法都市ジオの町マップに入る。（1と2は順不同）
  3. バドもコロナも仲間にしていない状態で、マイホームの寝室にいるサボテン君に話しかけ、「語りかける」を選ぶ。これ以降、バドが病気で倒れる。
  4. ドミナの町のドミナバザールでメイメイに占ってもらい、病気の子供はサボテンが助けるという話を聞く。サボテンの話が出るまで占ってもらうこと。
  5. マイホームの居間に入る。

進め方

  1. 寝室へ行くとサボテン君がおらず、書き置きが見つかる。バドの薬を探しに出たらしい。
  2. リュオン街道の大地の顔ガイアと話す。
  3. ジャングルのロシオッティの座で、しるきーと話す。
  4. 魔法都市ジオの魔法学園②（MAP17-6）で、ブラウニーと話す。
  5. 海賊船バルドの下甲板（MAP20-15）で、デイビッドと話す。
  6. ドミナの町のいなか道で、アマレットちゃんと話す。
  7. マイホームの自宅前のポストにいるサボテン君に話しかけるとクリア。サボテン君は寝室に戻り、バドの病気も治る。
  • しるきーをロシオッティの座に出現させるには、『獣王』をクリア（または失敗・消滅）したあと、森雨の園で彼女と話しておく。
  • デイビッドは、キルマ湖に入ってから『石の魚』をクリアするまでの間、海賊船バルドに入っても追い返されるため話せない。
  • アマレットちゃんは、『ディドルの手紙』の発生直前にディドルが噴水公園からいなくなった時点から、同イベントが発生するまでは出現しない。
  • バドは倒れてからこのイベントをクリアするまで、コロナはバドが倒れてからこのイベントが発生するまで、仲間にできない。
発生中はサボテン君が家にいないため、サボテンくん日記を書いてもらえない。日記を欠かさず埋めたいなら、このイベントをクリアするまでほかのイベントをクリアしないようにする。
