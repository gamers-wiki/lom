エスカデ編

カテゴリ：イベント攻略全7イベント

幼なじみのエスカデ、ダナエ、マチルダ、アーウィンの4人をめぐる物語。ドミナの町の宿屋で悩むダナエにつきあうところから始まり、断崖の町ガトの寺院を拠点にジャングル、キルマ湖、ウルカン鉱山、ミンダス遺跡をまわり、復活したルシェイメアでのアーウィンとの決戦まで、7つのイベントで構成されます。途中の選択でエスカデとダナエのどちらかが以後登場しなくなるため、分岐には注意が必要です。

ガイアの知恵

ガイアの知恵
日記No.3
発生条件リュオン街道の最初の分かれ道まで行くとドミナの町の宿屋にダナエが現れる。話しかけて「知ってる」または「知らない」→「魂はなくならない」→「ついて行く」と選び、仲間にNPCがいなければダナエが仲間になって発生
ランドドミナの町、リュオン街道
仲間になる人物ダナエ
入手なし
失敗・消滅ダナエを仲間から外すと失敗（断崖の町ガトに入っても別れてしまう）。宿屋の会話で上記以外の選択肢を選ぶと消滅。『ニキータ商い道中』と『まいごのプリンセス』のクリアまたは失敗後、あるいは『岩壁に刻む炎の道』と『うごめく森』のクリア後に断崖の町ガトへ入っても消滅

進め方

  1. ドミナの町の宿屋でダナエと話し、上記の順に選択肢を選んで仲間にする。
  2. リュオン街道を渓谷側の奥まで進み、ガイアと話す。
  3. ひとつ前の画面に戻ると、持たざる者の指輪をもらってクリア。ダナエは仲間から外れる。
ダナエと別れた時点で失敗になる。ガイアと話し終えるまで、断崖の町ガトには入らないこと。
クリア後、ダナエはドミナの町の客室①からいなくなる。

うごめく森

うごめく森
日記No.9
発生条件「ジャングル・妖精の森②に入る」「『獣王』のクリア（失敗・消滅でも可）後、ジャングル・森雨の園でしるきーにおまじないをかけてもらう」の両方を済ませたあと、ジャングル・ロシオッティの座でしるきーに話しかけて「はい」→「はい」と答える
ランドジャングル
関連NPCエスカデ（仲間にできない）
入手なし

進め方

  1. 『獣王』のあと、森雨の園に現れる森ペンギンのしるきーにおまじないをかけてもらう。西の森④から妖精の森①への通路ができる。
  2. ロシオッティの座でしるきーから頼まれてイベント発生。発生後は妖精の森②で入口へ飛ばされなくなる。
  3. 妖精の森②から左へ進み、一番奥へ向かう。剣士風の男（エスカデ）が修道女を助ける場面のあと、レッサーデビルとのバトルになる。
  4. 勝てばクリア。

ボス

レッサーデビル（妖精の森の奥）。立ち去れという忠告を無視していると襲ってくる。

エスカデが初めて登場するイベント。クリア後、ジャングル・ロシオッティの座にエスカデが現れ、仲間にできるようになる。森の中で会ったエスカデたちは、画面を切り替えるといなくなる。

二つの炎

二つの炎
日記No.7
発生条件『岩壁に刻む炎の道』と『うごめく森』のクリア後、エスカデを仲間にしていない状態で断崖の町ガトの町マップへ移動する。そのあと寺院の廊下にいるダナエと話してから夢見の間に入る
ランド断崖の町ガト
仲間になる人物エスカデ、ダナエ（どちらも進行中に仲間にできる）
入手AF『石の目玉』

進め方

  1. エスカデがいない状態でガトの町マップへ行くと、寺院へ向かうエスカデが見られる。エスカデを連れていても、ここに入ると自動的に仲間から外れる。この場面を見てからクリアまでは、ジャングルにエスカデは現れない。
  2. 寺院の廊下でダナエと話し、夢見の間に入るとイベント発生。「事情はのみこめたかい？」への答えはどちらでもよい。エスカデが去ったあとダナエに話しかけると、4人の関係について詳しい話が聞ける。
  3. 夢見の間から寺院の廊下へ出たあと、一度別のマップへ移動してから廊下へ戻るか、そのまま寺院を出るとマチルダがさらわれる。廊下に出てすぐ夢見の間へ戻った場合だけ、マチルダがニセの修道女にさらわれる場面を見られる。その直後にダナエに話しかけると、仲間にNPCがいない場合に限りダナエが仲間になる。
  4. ダンジョン（断崖の修験の道）に入ると、寺院側の入口にエスカデとダナエが現れる（ダナエは仲間にしていなかったときのみ）。どちらかと話すと、洞窟内部⑦と洞窟内部⑪で道を塞いでいた修道女が動き、奥へ入れるようになる。仲間にNPCがいない状態で話すと仲間にする選択肢が出る。仲間にしなかった場合、話し終えると彼らはどこかへ行ってしまう。
  5. 仲間にNPCがいない状態でダナエと話すか、ダナエを連れてエスカデと話したときだけ、瞑想の間の手前まで案内（ワープ）してもらえる。案内してもらうと必ずダナエが仲間になる。
  6. 瞑想の間で会話のあと、スプリガンとのバトル。勝つとアーティファクトを入手してクリア。エスカデかダナエを連れていた場合は仲間から外れる。

ボス

スプリガン（瞑想の間）。マチルダを取り戻した直後に襲ってくる。

クリア後、ダナエは断崖の町ガト・寺院の廊下に現れる。

流れ行くものたち

流れ行くものたち
日記No.11
発生条件下の「発生させるまで」を参照
ランド断崖の町ガト、キルマ湖
関連NPCダナエ（仲間にできない）
入手なし
失敗・消滅発生直前のマチルダとの会話で「断る」を選ぶと消滅

発生させるまで

  1. 『二つの炎』をクリアする。
  2. 断崖の町ガト・寺院の廊下でダナエに話しかけ、「ジャングル」か「妖精界」を選ぶ。「わからない」と答えている間は先へ進まない。
  3. いったんワールドマップへ出る。
  4. 寺院の廊下で修道女と話す。
  5. 夢見の間でマチルダに話しかけ、「引き受ける」か「こころにとめておく」を選ぶ。

『二つの炎』をクリアしたときに寺院の廊下に修道女が現れていることがあり、その場合は2と3を省ける。

手順5で「断る」を選ぶと、このイベントは二度と発生しなくなる。エスカデ編を進めるのに必須のイベントなので、以後のエスカデ編がすべて遊べなくなる。必ず「断る」以外を選ぶこと。

進め方

  1. キルマ湖の奥にある崖でトートに話しかける。トートがここに現れるのは『石の魚』のクリア後だけなので、先に済ませておかないと進まない。
  2. キルマ湖でダナエを追いかける。ダナエとアーウィンが言い争う場面を経て、ダナエが妖精の輪に消える。
  3. ダナエが消えた場所を調べると、グランシェとのバトル。
  4. 勝つと自動的に夢見の間へ移動し、マチルダに報告するとクリア。報告の選択肢は3つともどれでもよい。

ボス

グランシェ（キルマ湖の森の奥）。

イベント発生後の会話に出る選択肢は、会話内容が変わるだけで、進行には影響しない。

『二つの炎』クリア後、エスカデを連れずに断崖の町ガトの町マップへ入ると、エスカデはジャングルのロシオッティの座からいなくなる（それまでに一度もキルマ湖へ入っていなければ残る）。

クリア後、エスカデが仲間にいないときのみ、ウルカン鉱山の入口にポキールが現れる。『ポキール・夢への誘い』が発生するまで、断崖の町ガト・滝にエスカデと妖精が現れる。

ポキール・夢への誘い

ポキール・夢への誘い
日記No.15
発生条件『流れ行くものたち』と『鍛冶屋ただいま閉店中』のクリア後、エスカデを仲間にしていない状態でウルカン鉱山に入り、入口にいるポキールに話しかける
ランドウルカン鉱山（夢の中）
関連NPCエスカデ（仲間にできない）
入手なし
失敗・消滅現実のウルカン鉱山・入口でポキールに話しかけて「はい」を選ぶと失敗

進め方

  1. 発生すると自動的に夢の中のウルカン鉱山の入口へ移動する。
  2. 夢の中では、入口→地下3層①→鉱山の最深部の順に進む。入って最初の階段にいるポキールに話しかけて「はい」と答えると、地下3層①まで一気に運んでもらえる。
  3. 最深部で過去の場面を見終えると夢が終わる。
  4. 夢から戻ると、そばにいるエスカデに「オレとダナエのどちらにつくんだ？」と聞かれる。「エスカデに付く」を選ぶとそのままクリア。それ以外を選ぶと直後にエスカデとのバトルになり、勝てばクリア。

ボス

エスカデ（夢から戻った直後。「エスカデに付く」以外を選んだ場合のみ）。

夢の中の鉱山から外へ出ると、現実のウルカン鉱山に戻る。もう一度夢に入るには、現実の鉱山入口にいるポキールに話しかけて「いいえ」と答える。ここで「はい」と答えるとワールドマップへ出たあとイベントが失敗になる。ただし、このイベント発生中にワールドマップへ出るには、通常この方法しかない。

夢の中のウルカン鉱山には、このイベント発生中しか入れない。探索したいならクリア前に済ませておく。現実の鉱山に戻ってから奥へ進めば、発生中でも現実の鉱山内を探索でき、ワッツの店での買い物や他のイベントの進行もできる。

夢の中の鉱山は現実と違い、ワッツの店にワッツがいない、地下2層⑧と地下3層④から奥へ進める、玄室②でしばらく待つと謎の声が聞こえる、穴掘り団のアジトに詩集がない、地形自体が変わっているマップもある。

エスカデを連れているとウルカン鉱山の入口にポキールが現れない。また、エスカデがおらずポキールが現れる状態では、アナグマとっきゅうびんが使えない。

クリア後、ポキールはウルカン鉱山の入口からいなくなる。

彷徨の回廊

彷徨の回廊
日記No.13
発生条件『危険なアフタヌーンティー』と『ポキール・夢への誘い』のクリアまたは失敗後、エスカデを仲間にしていない状態で断崖の町ガトの町マップへ行き、そのあと夢見の間に入る
ランド断崖の町ガト、ミンダス遺跡
仲間になる人物エスカデまたはダナエ（風の塔でどちらか一方を必ず仲間にする）
入手なし

進め方

  1. 夢見の間に入ってイベント発生。ミンダス遺跡へ飛ばされる。このとき連れていたNPCは必ず仲間から外れる（ペットやゴーレムはそのまま）。
  2. 遺跡の入口から、妖精によって地下建造物の最深部へ飛ばされる。風の塔までは仲間なしで進む。
  3. 風の塔へは次の手順が最短。
    1. MAP11-12で下の花人を右へ動かす。
    2. MAP11-16で上の花人を右へ、下の花人を左へ動かす。
    3. MAP11-12で下の花人を左へ動かす。
    4. MAP11-7で上の花人を左へ動かす。
  4. 風の塔に入ると選択肢が出る。「ダナエに加勢」を選ぶとダナエが、それ以外を選ぶとエスカデが仲間になり、仲間にならなかったほうとバトルになる。
  5. 勝てばクリア。エスカデを仲間にしていた場合のみ、エスカデが仲間から外れる。

ボス

エスカデまたはダナエ（風の塔）。風の塔での選択で仲間にしなかったほうと戦う。

風の塔で倒したNPCは、以降二度と登場しない。エスカデとダナエのどちらを残すかは慎重に決めること。

イベント発生中はミンダス遺跡から出られない。遺跡の入口へ行くたびに必ず地下建造物へ飛ばされるので、誤って入口へ行かないこと。

発生中のみ、繁栄の跡⑦にニキータが現れる。お金を払うと風の塔まで案内（ワープ）してもらえる。金額は最初が500ルクで、上の手順2を済ませたあとは100ルク。これを使えば手順1のあとすぐに風の塔へ行ける。

クリア後、風の塔で加勢したほうのNPCが断崖の町ガト・夢見の間に現れる。

上天の光

上天の光
日記No.17
発生条件『彷徨の回廊』クリア後、断崖の町ガト・夢見の間に入る
ランド断崖の町ガト、ルシェイメア
仲間になる人物エスカデ、ダナエ（どちらも仲間にしなくても進行できる）
入手なし

進め方

  1. 夢見の間でマチルダからルシェイメアの話を聞く。会話のあと、もう一度マチルダに話しかけると AF『愛のブローチ』がもらえる。
  2. 『愛のブローチ』を設置するとルシェイメアが現れる。他のランドと違い、移動先に指定しただけで自動的に中へ入ってしまう。
  3. アーウィンを捜してルシェイメアの上を進む。腐乱小路⑥と落つる山脈⑤では入るたびに風の王セルヴァが現れる。
  4. ルシェイメアの先端でアーウィンとのバトル。勝てばエスカデ編クリア。

ボス

アーウィン（ルシェイメアの先端）。巨大なモンスターに変身したアーウィンと戦う。

ルシェイメアは入口から外へ出られない。外へ出るには、腐乱小路⑥か落つる山脈⑤に現れるセルヴァとの会話で「もうだめ」を選び、断崖の町ガト・カンクン鳥の巣へ移動するしかない。一度入ると簡単には出られないので、準備を整えてから移動すること。

『彷徨の回廊』でエスカデを仲間にしたのにルシェイメアへ連れてこなかった場合、哀を背にして（MAP24-30）に入ったときにエスカデが登場して死んでしまい、以降の物語に登場しなくなる。エスカデを残したいなら、必ず一緒にアーウィンのもとまで行くこと。

発生時の夢見の間には、『彷徨の回廊』の風の塔で仲間にしたNPCがいる。ダナエなら発生後も夢見の間に残るので、仲間にNPCがいないときに話しかければ仲間にできる。エスカデなら発生後にジャングルのロシオッティの座へ移動するので、仲間にするにはそこまで行く。ダナエを連れたまま発生させると、会話のあと一度ダナエが仲間から外れる。

エスカデ編のエンディングは、連れているNPCによって会話内容が少し変わる。クリア後はルシェイメアに二度と入れない。

クリア後、エスカデを仲間にしてクリアした場合はエスカデがジャングル・ロシオッティの座に現れ、そうでない場合はエスカデが登場しなくなる。マチルダは断崖の町ガト・夢見の間からいなくなる。
