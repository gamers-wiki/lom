やり込み・シークレット

カテゴリ：やり込みシークレット100件

物語を追うだけでは通り過ぎてしまうものを集めたカテゴリです。 条件を満たしたときだけ見られる場面、ボタン操作でできる小技、町や海岸で遊べるミニゲーム、 書斎の図鑑をそろえる手順を扱います。シークレットは全100件を4編に分けて並べ、 項目ごとに起きる場所・関わるイベント・見るための手順・起きることをまとめています。

このカテゴリは物語の先の内容を含みます。 見るための条件が物語の進みぐあいと結びついているため、場面の中身や終盤に出てくる名前を伏せずに書いています。 まだ知りたくないところがあるときは、先にイベント攻略を進めてから読んでください。

シークレット100件

シークレットは4編に分かれます。番号は100件の通し番号なので、どの編のページでも同じ番号で引けます。

  • シークレット：イベント編 … 51件。条件を満たさないと見られない場面、話しかける順番や返事で変わる反応、連れている仲間で増えるやり取り
  • シークレット：バトル編 … 14件。ボタン操作でできる小技、レベルアップでの能力値の伸ばしかた、属性レベルの上げかた、もうひとりの主人公を仲間にする条件
  • シークレット：バラエティ編 … 26件。クリア後の2周目、名前入力やセーブデータの仕掛け、漢字表記の読み、シリーズから受け継いだ名前
  • シークレット：ミニゲーム編 … 9件。ドミナの町の酒場、ワールドマップ、魔法都市ジオの闘技場、マドラ海岸で遊べるもの

ミニゲーム編のうちポケットステーションを使う項目は、遊ぶのに別の機器が要るので、ポケットステーションのミニゲームに分けてまとめています。そのためミニゲーム編のページには、本編だけで遊べる項目が並びます。

ミニゲーム

遊べるものは、遊ぶ場所と必要なものが違うので、本編だけで遊べるものとポケットステーションを使うものに分けています。

  • シークレット：ミニゲーム編 … 酒場の捕まえもの、ワールドマップの隠しゲーム、闘技場の対戦、カニ踏みと、その結果で変わるマイホーム
  • ポケットステーションのミニゲーム … 『リング・りんぐ・ランド』の遊びかたを13節に。ペットのおでかけ、コースのマスとバトル、持ち帰るアイテムと経験値

ポケットステーションはPS 版の周辺機器です。HD リマスター版にはこのしくみがありません。ペットそのものの育てかたはペットの基本にまとめています。

図鑑を集める

マイホームの書斎で読める図鑑は全10冊です。 手に入れかたも、全項目を埋めるまでの手間も冊ごとに違い、手に入れた時点で埋まっているものもあれば、 決まった場所へ行かないと埋まらないものもあります。

  • 図鑑10冊の集めかた … 冊ごとの入手方法・項目数・全項目を埋める手順
  • 人物図鑑の記載条件 … 人物図鑑に載る79人ぶんの条件

人物図鑑は載る条件が人物ごとに分かれるため、記載条件だけはキャラクターのカテゴリにあります。手に入れかたと項目数は、残る9冊とあわせて図鑑10冊の集めかたにまとめています。

取り返しのつかないこと

イベントには、進めかたによってはクリアできずに終わる失敗と、 発生前にほかのイベントを進めると二度と起こらなくなる消滅があります。 シークレットにも、関わるイベントが消えると見られなくなる場面が含まれます。 どのイベントに失敗・消滅があるかはイベントのカテゴリにまとめてあるので、順番が気になるときは先にそちらを見てください。

  • イベントの発生条件一覧 … 68本のイベントの発生条件と、失敗・消滅の有無を1つの表に
  • イベント攻略 … 群ごとの進めかたと、いつ消えるか

見たい場面が決まっているときは、関わるイベントを先に確かめてください。各編のページには関わるイベントを書いてありますが、そのイベントが消える条件までは書いていません。消える条件はイベント側のページにあります。
