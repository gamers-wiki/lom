マイホーム HOME

カテゴリ：ランド図鑑No.1
マイホーム
種類拠点
出すアーティファクトAF『ポスト』（ゲーム開始時から持っている）
関係するイベント『幸せの四つ葉』『コスモ』『小さな魔法使い』ほか（下の一覧を参照）

主人公の家があるランドで、冒険の出発点になる場所です。寝室ではサボテンくん日記を読み、書斎では各種の図鑑を見ることができます。作成編のイベントを終えると、敷地にあるペット牧場・果樹園・作成小屋が使えるようになり、拠点としての役割が広がります。

エリア構成

ワールドマップから入ると自宅前に着きます。家の中は居間を経て書斎と寝室に分かれ、家の外は自宅前からペット牧場・果樹園・作成小屋へ道が伸びています。作成小屋の奥はエントランスを経て 3 つの作成室につながっていますが、それぞれ対応するイベントを終えるまでは使えません。

  • 自宅前（MAP1-1）：スタート地点。ワールドマップへの出入口。瑠璃がいる
  • 居間（MAP1-2）：バドとコロナがいる。宝箱がひとつ
  • 書斎（MAP1-3）：図鑑を読める
  • 寝室（MAP1-4）：セーブポイント。サボテン君とサボテンくん日記がある
  • ペット牧場（MAP1-5）：敷地内の牧場。奥にペット小屋
  • ペット小屋（MAP1-6）：牧場の建物の中
  • 果樹園（MAP1-7）：『果樹園』発生前は荒れた空き地。発生後は木が育ち、収穫箱が置かれる
  • 作成小屋（MAP1-8）：初期状態と、3 つの作成イベントをすべて終えたあとの最終形で外観が変わる
  • 寝室窓際（MAP1-9）：自宅の屋根裏にある小部屋。『ティアストーン』クリア時に入る
  • 作成小屋エントランス（MAP1-10）：作成室への入口。初期状態と最終形がある
  • 武具作成室（MAP1-11）：『武器防具作成』クリア後
  • 魔法楽器作成室（MAP1-12）：『楽器作成』クリア後
  • ゴーレム研究室（MAP1-13）：『ゴーレム作成』クリア後。生命球とロジックブロック壺がある

施設・住人

  • セーブポイント：寝室
  • サボテンくん日記：寝室。これまでの出来事をふり返れる
  • 図鑑：書斎
  • 武具作成室・魔法楽器作成室・ゴーレム研究室：作成小屋の奥。対応するイベントのクリア後に使える
  • 果樹園の収穫箱：『果樹園』発生後、実った果物を受け取る
  • 仲間にできる人物：バド、コロナ（居間）、瑠璃（自宅前）

ここで起こるイベント

  • 『幸せの四つ葉』 … 真珠姫に会うため家へ戻る
  • 『コスモ』 … 瑠璃といっしょに真珠姫を捜しに出る
  • 『小さな魔法使い』 … ドミナの町の異変を耳にする
  • 『賢人を探せ！』 … バドとともに賢人を捜しに出る
  • 『お父さんのほうき』 … コロナのほうきが見当たらなくなる
  • 『サボテン』 … サボテン君がいなくなる
  • 『ディドルいやになる』 … 自宅に立ち寄る
  • 『武器防具作成』 … 武器・防具の作りかたを教わる
  • 『楽器作成』 … 楽器の作りかたを教わる
  • 『ゴーレム作成』 … ゴーレムの作りかたを教わる
  • 『果樹園』 … 荒れた果樹園をよみがえらせる
  • 『ペット牧場』 … ペットの育てかたを教わる
  • 『夢の檻の中へ』 … 草人の役割を知る
果樹園・作成小屋・作成小屋エントランスは、対応するイベントの前後で見た目が変わります。作成小屋の外観が最終形になるのは、『武器防具作成』『楽器作成』『ゴーレム作成』の 3 つをすべて終えたあとです。
