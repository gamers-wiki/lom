断崖の町ガト GATO GROTTOES

カテゴリ：ランド図鑑No.6
断崖の町ガト
種類町（ダンジョンを併設）
出すアーティファクトAF『炎』
関係するイベント『岩壁に刻む炎の道』『二つの炎』『上天の光』ほか（下の一覧を参照）

切り立った崖に建物が張りつく、聖なる風に守られた町です。火と風の精霊を祭る癒しの寺院があり、修道女たちが暮らしています。町の外れからは「断崖の修験の道」と「洞窟内部」が入り組んだダンジョンが広がり、その奥にある瞑想の部屋や、滝、大カンクン鳥の巣が、エスカデ編を中心とした多くのイベントの舞台になります。

エリア構成

町は町マップを中心に、門前町、ショップ、断崖の道、癒しの寺院、滝、カンクン鳥の巣などへ行き来します。寺院は礼拝堂から廊下を経て 2 つの修道場と夢見の間につながっています。ダンジョン部分は、屋外の「断崖の修験の道」と屋内の「洞窟内部」が交互に現れる構造で、一度洞窟に入ると別の修験の道へ抜け、そこからまた別の洞窟へ入る、というように行き来をくり返しながら奥へ進みます。最奥が瞑想の部屋です。

ここで起こるイベント

  • 『岩壁に刻む炎の道』 … 宝石泥棒を追う
  • 『二つの炎』 … 連れ去られたマチルダを追う
  • 『流れ行くものたち』 … マチルダの頼みを引き受ける
  • 『彷徨の回廊』 … 寺院を訪れる
  • 『上天の光』 … 愛のブローチを預かる
  • 『続・ニキータ商い道中』 … ニキータにつきあう
  • 『ニキータ・最後の商い？』 … ニキータにつきあう
  • 『シュタインベルガー』 … 酒造りを手伝う
  • 『賢人を探せ！』 … 賢人セルヴァに会う

ダンジョン部分へは、『岩壁に刻む炎の道』が起きてから断崖の修験の道②に入れるようになります。また『二つの炎』の発生後には、洞窟内部⑥から⑦へ抜ける道と、洞窟内部⑫の通路が開きます。滝から入る断崖の修験の道⑩は、酒樽の並ぶ洞窟内部㉑へ続いています。

ペット・精霊：瞑想の部屋で不定形系のヒナと精霊に会えます（それぞれ『ペット牧場』『楽器作成』クリア後）。
