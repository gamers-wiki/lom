ドミナの町 DOMINA

カテゴリ：ランド図鑑No.2
ドミナの町
種類町
出すアーティファクトAF『積み木の町』（ゲーム開始時から持っている）
関係するイベント『ニキータ商い道中』『小さな魔法使い』『アレクサンドル』ほか（下の一覧を参照）

主人公が最初に足を踏み入れる、にぎやかな町です。住人が多く、その人たちにまつわるイベントの舞台になることがとくに多いランドです。武器屋と原料屋、宿屋がそろっているほか、ドミナバザールにいるメイメイのフルーツ占いは、次に何をすればよいか迷ったときの手がかりになります。

エリア構成

町全体を見わたす町マップを中心に、各エリアへ移動します。ワールドマップから入ると商店街に着き、そこから町マップを通って教会、ドミナバザール、いなか道、噴水公園へ行けます。商店街には宿屋と酒場、武器屋があり、宿屋の奥に客室が 3 部屋あります。いなか道の先の町はずれは、イベントのときだけ様子が変わる場所です。

  • 商店街（MAP2-1）：スタート地点。ワールドマップへの出入口。空き家、酒場、宿屋、武器屋の入口が並ぶ
  • 酒場「アマンダ＆パロット亭」（MAP2-2）：真珠姫と瑠璃がいる
  • 宿屋「マナの祝福亭」（MAP2-3）：セーブポイント。奥に客室が 3 つ
  • 客室①（MAP2-4）：ダナエがいる
  • 客室②（MAP2-5）：原料屋
  • 客室③（MAP2-6）：宝箱がひとつ
  • ドミナバザール（MAP2-7）：ニキータがいる。メイメイのフルーツ占い
  • 風なびく草原の教会（MAP2-8）：畑の先に建つ教会。中が講堂
  • 聖マナ教会講堂（MAP2-9）：教会の内部
  • 武器屋「ジェマの騎士」（MAP2-10）：武器屋。奥にマークの部屋とレイチェルの部屋
  • マークの部屋（MAP2-11）
  • レイチェルの部屋（MAP2-12）
  • 女神の使いの噴水公園（MAP2-13）：翼のある像の噴水がある広場
  • いなか道（MAP2-14）：民家と畑のあいだの道。先が町はずれ
  • 町はずれ（MAP2-15）：ふだんは何もない草地。イベント時はカボチャだらけの景色に変わり、バトルが起こる

施設・住人

  • 武器屋：武器屋「ジェマの騎士」
  • 原料屋：宿屋の客室②
  • セーブポイント：宿屋「マナの祝福亭」
  • フルーツ占い：ドミナバザールのメイメイ。進めかたに迷ったときの助けになる
  • 仲間にできる人物：真珠姫、瑠璃（酒場）、ダナエ（客室①）、ニキータ（ドミナバザール）
  • ペット・精霊：町はずれで、『ペット牧場』クリア後に獣系のヒナ、『楽器作成』クリア後に精霊に会える

ここで起こるイベント

  • 『アレクサンドル』 … 真珠姫を仲間にする
  • 『ガイアの知恵』 … ダナエにつきあう
  • 『ニキータ商い道中』 … 盗賊退治の依頼を引き受ける
  • 『小さな魔法使い』 … いたずらをする魔法使いをこらしめる
  • 『サボテン』 … サボテン君の行方を追う
  • 『ディドルの手紙』 … ディドルがいなくなる
  • 『ディドルさらわる』 … ディドルがいなくなる
  • 『レイチェル』 … レイチェルに異変が起こる
  • 『もう1人の自分』 … ニセモノを退治する
  • 『Pちゃん』 … Pちゃんを元気にする
  • 『楽器作成』 … コインのもらいかたを教わる
  • 『ペット牧場』 … ヒナのつかまえかたを教わる
町の中で戦いになるのは町はずれだけで、それも特定のイベントのあいだに限られます。ふだんは安全に歩き回れる町なので、買い物やセーブの拠点として使えます。
