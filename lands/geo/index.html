魔法都市ジオ GEO

カテゴリ：ランド図鑑No.17
魔法都市ジオ
種類町
出すアーティファクトAF『魔導書』（『災いを呼ぶ人形』のクリア時に入手。代わりに『群青の守護神』のクリア時にもらえることもある）
関係するイベント数が多いので下の一覧を参照
仲間にできるNPC真珠姫、瑠璃、ニキータ、エメロード
ペット・ヒナなし
出現モンスターボスのジュエルビースト1のみ（『幸せの四つ葉』）

魔法の研究が盛んな、城壁に囲まれた都市。目抜き通りの奥にある魔法学園では日替わりで先生が授業をしていて、クリスティーの宮殿の地下には旅の仲間と腕くらべができる闘技場がある。宝石泥棒編の中心となる町で、『幸せの四つ葉』『アレクサンドル』『フローライト』『ティアストーン』の舞台になるほか、ニキータ編・ギルバート編など多くのイベントが関係する。

エリア構成

スタート地点は城門入口（MAP17-1）で、ここにセーブポイントがある。城門をくぐると町マップに出て、町マップからは町のすべての場所へ直接入れる。目抜き通り（MAP17-2）には楽器の店と喫茶店が面していて、通りの奥が魔法学園。学園は3つの区画と図書室・学園長室からなる。町の高台にある宮殿（MAP17-13・17-14）の中には美術品講堂と美術品倉庫があり、その地下が闘技場（MAP17-17）になっている。

  • 城門入口（MAP17-1）：スタート地点。セーブポイントがある。ワールドマップへの出口
  • 目抜き通り（MAP17-2）：町の大通り。楽器の店と喫茶店の入口がある
  • 楽器の店「レスターの竪琴」（MAP17-3）：武器屋
  • 喫茶「ごめんねカール」（MAP17-4）：原料屋。量産型ティーポがいる
  • 魔法学園①〜③（MAP17-5〜17-7）：①が学園の門、②が中庭、③が教室。②から図書室と学園長室へ
  • 図書室（MAP17-8）：エメロードがいる
  • 学園長室（MAP17-9）：学園長ヌヌザックの部屋
  • 宝石店「ウェンデルの秘宝」（MAP17-10）：宝石屋。瑠璃がいる。『ティアストーン』の発生以降は廃屋になり、店は使えなくなる
  • 宝石箱パンドラ（MAP17-11）：真珠姫、瑠璃がいる。『フローライト』の発生中は、ここからデュマ砂漠のオアシス（夢）へ移動する
  • フルーツパーラー（MAP17-12）：ニキータがいる
  • 宮殿①・②（MAP17-13・17-14）：①が宮殿の外観、②が門の内側の庭
  • 美術品講堂（MAP17-15）：宮殿の中の広間。美術品倉庫へ続く
  • 美術品倉庫（MAP17-16）：宮殿の奥の倉庫
  • 闘技場（MAP17-17）：宮殿の地下。ドゥエルに話しかけると使える。『幸せの四つ葉』の発生中は明るい闘技場になり、ジュエルビースト1と戦う
  • 塔の上（MAP17-18）：『幸せの四つ葉』の途中で場面として使われる場所

ここで起こるイベント

  • 『幸せの四つ葉』 … エメロードの姉たちを捜す。闘技場でジュエルビースト1と戦う
  • 『アレクサンドル』 … 心の鍵を探す
  • 『フローライト』 … 蛍姫を救う。宝石箱パンドラから夢の中のオアシスへ
  • 『ティアストーン』 … 王杓を託される。宝石店「ウェンデルの秘宝」が廃屋になる
  • 『続々・ニキータ商い道中』 … ニキータに同行する
  • 『ニキータ・最後の商い？』 … ニキータをクリスティーに会わせる
  • 『シュタインベルガー』 … 喫茶店のバーテンから話を聞く
  • 『サボテン』 … サボテン君の行方を追う
  • 『ギルバート・愛の出席簿』 … 授業をボイコットしている学生を説得する
  • 『ギルバート・愛の履歴書』 … ギルバートの石像を見つける
  • 『レイチェル』 … 家出したレイチェルの行方を追う

曜日を進めたいとき。喫茶「ごめんねカール」にいる量産型ティーポに話しかけると、曜日を1日進められる。魔法学園の授業は曜日ごとに先生が変わるので、目当ての授業を受けたいときに使える。
