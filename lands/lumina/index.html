月夜の町ロア LUMINA

カテゴリ：ランド図鑑No.8
月夜の町ロア
種類町
出すアーティファクトAF『蛍袋のランプ』
関係するイベント『精霊の光』『たゆたう歌声』『続々・ニキータ商い道中』ほか（下の一覧を参照）

夜が明けることのない、満月の光に照らされた町です。残月の路地の奥にはリュミヌーのランプ屋があり、アナグマたちが集まる酒場「悪魔のぼったくり亭」では、マスターからアナグマ語を教えてもらえます。武器屋・原料屋・宝石屋がそろっていて、モンスターは出ません。

エリア構成

町マップを中心に、酒場と 3 本の路地へ移動します。悪魔のぼったくり亭からは武器屋と半月の路地へ、半月の路地からは鉱物屋へ行けます。明月の路地の先が宝石屋で、残月の路地の先がランプ屋です。

  • 悪魔のぼったくり亭（MAP8-1）：アナグマたちの集まる酒場。マスターにアナグマ語を教わる
  • 武器屋「世界樹の呼び声」（MAP8-2）
  • 半月の路地（MAP8-3）：宝箱がひとつ。ゴブリンがいる
  • 鉱物屋「マミーシーカー」（MAP8-4）：原料屋
  • 明月の路地（MAP8-5）
  • 宝石屋「ジェシカの片思い」（MAP8-6）：セーブポイント。ニキータがいる
  • 残月の路地（MAP8-7）
  • ランプ屋「ライムライト」（MAP8-8）：リュミヌーの店

施設・住人

  • 武器屋：武器屋「世界樹の呼び声」
  • 原料屋：鉱物屋「マミーシーカー」
  • 宝石屋：宝石屋「ジェシカの片思い」
  • セーブポイント：宝石屋「ジェシカの片思い」
  • 仲間にできる人物：ニキータ（宝石屋）

宝箱・入手アイテム

エリア中身条件・備考
半月の路地漆黒のはね

ここで起こるイベント

  • 『続々・ニキータ商い道中』 … ニキータにつきあう
  • 『シュタインベルガー』 … 心の樽を手に入れる
  • 『賢人を探せ！』 … 賢人ポキールに会う
  • 『精霊の光』 … アナグマにランプを売る
  • 『たゆたう歌声』 … リュミヌーを捜す
  • 『ギルバート・愛の履歴書』 … ギルバートのことをリュミヌーに伝える
  • 『ディドルいやになる』 … ディドルがシャドールにさらわれる
ペット：半月の路地に、このランドの木レベルと闇レベルがどちらも 3 のときゴブリン（グリ）がいます。町の中にモンスターは出現しません。
