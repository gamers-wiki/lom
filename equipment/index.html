武器・防具・楽器

カテゴリ：武器・防具・楽器

装備は買うだけでなく、素材から作り、あとから改造して育てられます。 ここでは装備のしくみ、作成以外で手に入るものの一覧、主原料から作れるもの、改造でできることをまとめています。

装備のしくみ

  • 武器・防具・楽器の基本 … 11系統の武器、12種類の防具、4系統の楽器の性質
  • お店の品ぞろえ … 店の種類と、店レベルで変わる並び

作成以外で手に入るもの

  • 武器リスト … 122種
  • 防具リスト … 77種
  • 楽器リスト … 32種

作って手に入れる

  • 武具作成の基本 … 作れるようになるまでと、攻撃力・防御力の決まりかた
  • 作成できる武器 … 主原料53種と武器系統の組み合わせ
  • 作成できる防具 … 主原料と防具の種類の組み合わせ
  • 楽器の作成と精霊のコイン … 使える魔法はコインで決まる

改造で育てる

  • 改造のしくみ … 副原料で性能を変える
  • 副原料の効果 … 130種類の効果
  • シークレットパワー … 68種類の特殊能力
  • 属性レベルの変化
  • 付加属性・属性耐性・能力値ボーナス
