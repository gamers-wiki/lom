シークレットパワー

カテゴリ：武器・防具・楽器全68種

シークレットパワーは、改造で武器・防具に宿る特殊な力です。能力値ボーナスや属性レベルを動かすもの、大技や状態異常耐性を備えさせるもの、ほかのシークレットパワーの効果を変えるものまで全 68 種あります。ここでは 11 の系統ごとに、宿らせる副原料・予約に必要な属性レベル・効果をまとめています。

  • 武器・防具・楽器の入口
  • 改造のしくみ
  • 付加属性・属性耐性・能力値ボーナス
  • 属性レベルの変化

シークレットパワーとは

シークレットパワーは、武器・防具に宿ってさまざまな効果をもたらす特殊な力です。効果は種類ごとに決まったタイミングで発揮され、宿っているあいだは基本的に消えません。

同時に宿せる数は決まっています。武器・防具には 3 つまで、楽器にはひとつだけです。武器・防具に 3 つ宿っている状態で 4 つ目が宿ると、もっとも古くに宿ったものがはずれます。

小悪魔系は、はずれかたが違います。一番下の欄にあっても、新しいシークレットパワーが宿ったときにはずれません。ただし、クラウンガーリックか聖水を副原料にして改造したときだけは、ほかと同じようにはずれます。

宿らせるまでの流れ

宿らせるには改造が 2 回必要です。目当てのシークレットパワーを秘めた副原料で改造すると予約された状態になり、もう一度改造を行なったときにはじめて宿ります。予約するには、そのシークレットパワーに決められた属性レベルの条件を満たしていなければなりません。

手順とつまずきやすいところは改造のしくみにまとめています。予約条件になる属性レベルの上げかたは属性レベルの変化、能力値ボーナスの段階と変化の範囲のランクは付加属性・属性耐性・能力値ボーナスにあります。

楽器に宿るもの

楽器は改造できないため、シークレットパワーは作成のときに使った精霊のコインで決まります。楽器に宿るのは精霊系の 8 種で、これはその楽器で使える魔法の属性を表すものです。武器・防具のときとは違い、能力値ボーナスが増えることはありません。どの楽器でどの魔法が使えるかは楽器リスト、魔法そのものの性能は魔法リストにあります。

組み合わせで効果が変わるもの

シークレットパワーには、ほかのシークレットパワーが同時に宿っているかどうかで結果が変わるものがあります。3 つの枠に何を入れるかを決めるときは、ここを先に確かめます。

小悪魔系が邪神七将系に変わる

『神々の黄昏』が宿ると、同時に宿っている小悪魔系のシークレットパワーが邪神七将系に変化します。変化したあとに『神々の黄昏』がはずれても、小悪魔系にもどることはありません。

小悪魔（怠惰）月の魔女
小悪魔（嫉妬）蝿の王

小悪魔系は変化の範囲が「全：-1〜+3」、邪神七将系は「全：-10〜+20」です。『堕天使』など邪神七将系は、ひとつの能力値ボーナスを大きく上げるかわりに、そのほかを下げます。

はずれかたを変えるもの

  • 『ささげられし娘』 … すべて…邪神七将系のシークレットパワーがはずれる状況になったとき、身がわりとなってはずれる
  • 『かどわかされし娘』 … すべて…『死せる大地』の効果を打ち消す。ただし、こちらのほうが『死せる大地』よりも先に宿っているときにかぎる
  • 『暁の娘』 … 武器・防具からはずれるときに192のエネルギーを生み出す。また、改造に使われた副原料のエネルギーが24以下だったとき、192のエネルギーを生み出して強制的にはずれる

『暁の娘』が生み出すエネルギーは、属性レベルを 6 以上に上げるときの要になります（属性レベルの変化）。

ほかのシークレットパワーを強めるもの

  • 『塔』 … すべて…同時に宿っている、『魔法使い』および『魔女』の効果を大きくする
  • 『都市』 … すべて…同時に宿っている『道化師』の効果を大きくする

強められる側の効果は次のとおりです。

  • 『魔法使い』 … すべて…光、木、火、土の各属性への抵抗度を下げる。同時に『塔』が宿っていると効果が大きくなる（ただし、『魔法使い』をふたつ以上宿らせるほうがさらに効果大）
  • 『魔女』 … すべて…闇、金、風、水の各属性への抵抗度を下げる。同時に『塔』が宿っていると、やや効果が大きくなる
  • 『道化師』 … 変化の範囲が 全：-3〜+9（同時に『都市』が宿っていると、-5〜+12）

『魔法使い』と『魔女』は、属性レベルを上げるために必要なエネルギー量を減らします。2 つ以上宿らせるほど効果が大きくなります（属性レベルの変化）。

HP の自動回復にかかわるもの

  • 『世界樹』 … すべて…HPの自動回復の速度が上昇。この効果が複数もたらされた場合は効果が重複
  • 『天秤』 … すべて…バトル中、つねにHPが自動回復するかわりに戦闘不能状態が解除されなくなる。同時に『いばらのしげみ』が宿っている場合は、あとに宿ったほうの効果が優先される
  • 『いばらのしげみ』 … 防具…e・f・g・h【各+50%】。ただし、バトル中にHPが自動回復しなくなる
  • 『天かける娘』 … マント…バトル中、つねにHPが自動回復する。同時に『いばらのしげみ』が宿っている場合は、あとに宿ったほうの効果が優先される

HP が自動回復するかどうかは、あとに宿ったほうの効果が優先されます。『いばらのしげみ』は防具の守りを大きく上げますが、『天秤』や『天かける娘』のあとに宿らせると自動回復が止まります。『天秤』を選ぶときは、戦闘不能状態が解除されなくなることも合わせて考えます。

リング・ペンダントに宿すもの

  • 『不死鳥』 … リング、ペンダント…『火山』と同時に宿っていれば、装備者のHPがゼロになったときに最大値まで回復させて、はずれる。『天秤』が同時に宿っていると効果が発揮されない
  • 『一角』 … リング、ペンダント…戦闘不能状態が解除されるまでの時間が半分になる。この効果は、『泉』と同時に宿ったときに備わる
  • 『リンゴ園の娘』 … リング…戦闘不能状態が解除されるまでの時間が半分になる
  • 『豊饒の女神』 … リング…主人公が得た経験値がパーティー全員に均等にわけ与えられる

この 4 つは、どれもリングかペンダントに宿したときだけ効きます。『不死鳥』と『一角』は、それぞれ『火山』・『泉』と組み合わせてはじめて効果が出るので、3 つの枠のうち 2 つを使います。『リンゴ園の娘』と『豊饒の女神』は、ほかのシークレットパワーと組み合わせなくても効きます。

敵が落とすものを増やすもの

  • 『愛の女神』 … ペンダント…敵が落とすルクの数が1個増加
  • 『妖精（家事）』 … リング…敵が落とすルクの数が1個増加
  • 『妖精（靴）』 … サンダル…敵が落とすジェムの数が1個増加

属性の強弱関係を変えるもの

  • 『太古の月』 … すべて…属性レベルにおける属性の強弱関係がなくなる
  • 『鏡面世界』 … すべて…属性レベルにおける属性の強弱関係が逆転する

属性レベルには、強い属性のレベルが高いと弱い属性のレベルが上がらないという関係があります。『太古の月』はこの関係をなくすので、火と水のように打ち消しあう属性のレベルを同時に高くできます（属性レベルの変化）。属性ごとのダメージの増減はダメージと属性・状態異常にまとめています。
